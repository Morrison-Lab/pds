# Welcome

These notes collect the probability that data science courses assume.

## 0.1 Using these notes in another site

Course sites include these notes as a git submodule named `pds` at the site’s root, and include fragments with paths that start with `pds/`.

Quarto resolves `@id` cross-references only within one rendered page, so a host site that links to a result here uses an explicit link to the page and anchor.
