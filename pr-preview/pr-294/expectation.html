DefDefinition 1 (Expectation, expected value, population mean)

Definition 1 (Expectation, expected value, population mean) The expectation, expected value, or population mean of a discrete random variable \(X\), denoted \({\mathbb{E}\mathopen{}\left[X\right]\mathclose{}}\), \(\mu(X)\), or \(\mu_X\), is the mean of \(X\)’s possible values [1], weighted by the probability mass function of those values:

\[{\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} \stackrel{\text{def}}{=}\sum_{x \in \mathcal{R}(X)} x \cdot \mathbb{P}(X=x)\]

The expectation of a continuous random variable \(X\) with probability density function \(\operatorname{p}(X=x)\) is the mean of \(X\)’s possible values, weighted by that density:

\[{\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} \stackrel{\text{def}}{=}\int_{x\in \mathcal{R}(X)} x \cdot \operatorname{p}(X=x)\,dx\]

In both cases, the expectation is defined only when the sum or integral converges absolutely, that is, when it is finite with \(\mathopen{}\left|x\right|\mathclose{}\) in place of \(x\).

RemarkRemark 1 (Expectation is a probability-weighted average)

Remark 1 (Expectation is a probability-weighted average). The expectation of a random variable \(X\) is a weighted average of the values of \(X\), and the probabilities are the weights.

  • A discrete random variable has a sum over its possible values. Each value \(x\) is multiplied by its weight \(\mathbb{P}(X=x)\), and the products are added. The weights are non-negative and add to \(1\).
  • A continuous random variable has an integral over its possible values. Each value \(x\) is multiplied by its weight, the density \(\operatorname{p}(X=x)\), and the products are accumulated. The density is non-negative and integrates to \(1\).

The mean of \(n\) numbers \(y_1, \ldots, y_n\) is the special case with every weight equal to \(1/n\):

\[\frac{1}{n}\sum_{i=1}^ny_i = \sum_{i=1}^ny_i \cdot\frac{1}{n}\]

A value with a larger probability counts for more in the expectation. The expectation is the balance point of the possible values: the point where a ruler would balance if each value \(x\) carried a weight proportional to \(\mathbb{P}(X=x)\).

ExmExample 1 (Expectation of a fair die roll)

Example 1 (Expectation of a fair die roll) Let \(Y\) be the result of a fair die roll, so the range is \(\mathcal{R}(Y) ={\mathopen{}\left\{1, 2, 3, 4, 5, 6\right\}\mathclose{}}\) and \(\mathbb{P}(Y=y) = 1/6\) for each \(y\) in the range. Every value has the same weight, so the expectation is the ordinary mean of \(1, \ldots, 6\):

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} &= \sum_{y \in {\mathopen{}\left\{1, 2, 3, 4, 5, 6\right\}\mathclose{}}} y \cdot\mathbb{P}(Y=y) && \text{(definition of expectation for discrete r.v.)}\\ &= \mathopen{}\left(1 + 2 + 3 + 4 + 5 + 6\right)\mathclose{} \cdot\frac{1}{6} && \text{(every weight is } 1/6 \text{)}\\ &= \frac{21}{6} && \text{(add)}\\ &= 3.5 && \text{(divide)} \end{aligned} \]

Now load the die so that the result \(6\) has probability \(1/2\), and each of \(1, \ldots, 5\) has probability \(1/10\). The weights still add to \(1\), and the expectation moves toward \(6\):

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} &= \mathopen{}\left(1 + 2 + 3 + 4 + 5\right)\mathclose{} \cdot\frac{1}{10} + 6 \cdot\frac{1}{2} && \text{(weights } 1/10 \text{ and } 1/2 \text{)}\\ &= 1.5 + 3 && \text{(multiply)}\\ &= 4.5 && \text{(add)} \end{aligned} \]

ExmExample 2 (The standard Cauchy distribution has no expectation)

Example 2 (The standard Cauchy distribution has no expectation) A random variable whose expectation is not defined is not exotic. Let \(X\) have the standard Cauchy distribution, with density \(\operatorname{p}(X=x) = \frac{1}{\pi(1 + x^2)}\) for every real \(x\). For \(x \ge 0\), \(\frac{1}{2\pi}\log(1 + x^2)\) is an antiderivative of \(\mathopen{}\left|x\right|\mathclose{} \cdot\frac{1}{\pi(1 + x^2)} = \frac{x}{\pi(1 + x^2)}\), and for \(x \le 0\), \(-\frac{1}{2\pi}\log(1 + x^2)\) is an antiderivative of \(\mathopen{}\left|x\right|\mathclose{} \cdot\frac{1}{\pi(1 + x^2)} = \frac{-x}{\pi(1 + x^2)}\). So, integrating over each half-line:

\[ \begin{aligned} \int_{0}^{\infty} \mathopen{}\left|x\right|\mathclose{} \cdot\frac{1}{\pi(1 + x^2)}\,dx &= \lim_{b \to \infty} \mathopen{}\left[\frac{1}{2\pi}\log(1 + x^2)\right]\mathclose{}_{0}^{b} && \text{(antiderivative on } [0, \infty) \text{)} \\ &= \lim_{b \to \infty} \frac{1}{2\pi}\log(1 + b^2) && \text{(evaluate at the bounds; } \log 1 = 0 \text{)} \\ &= \infty && \text{(} \log(1 + b^2) \to \infty \text{ as } b \to \infty \text{)} \end{aligned} \]

\[ \begin{aligned} \int_{-\infty}^{0} \mathopen{}\left|x\right|\mathclose{} \cdot\frac{1}{\pi(1 + x^2)}\,dx &= \lim_{a \to -\infty} \mathopen{}\left[-\frac{1}{2\pi}\log(1 + x^2)\right]\mathclose{}_{a}^{0} && \text{(antiderivative on } (-\infty, 0] \text{)} \\ &= \lim_{a \to -\infty} \frac{1}{2\pi}\log(1 + a^2) && \text{(evaluate at the bounds; } \log 1 = 0 \text{)} \\ &= \infty && \text{(} \log(1 + a^2) \to \infty \text{ as } a \to -\infty \text{)} \end{aligned} \]

Both halves diverge, so \(\int_{-\infty}^{\infty} \mathopen{}\left|x\right|\mathclose{} \cdot\frac{1}{\pi(1 + x^2)}\,dx\) diverges, and by Definition 1, \(X\) has no expectation.

LemTheorem 1 (Expectation of the Bernoulli distribution)

Theorem 1 (Expectation of the Bernoulli distribution) If \(X \sim \operatorname{Ber}(\pi)\) (Bernoulli distribution), that is, \(\mathbb{P}(X = 1) = \pi\) and \(\mathbb{P}(X = 0) = 1 - \pi\), then:

\[{\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} = \pi\]

ProofProof

Proof. \[ \begin{aligned} {\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} &= \sum_{x\in \mathcal{R}(X)} x \cdot\mathbb{P}(X=x) && \text{(definition of expectation for discrete r.v.)} \\&= \sum_{x\in {\mathopen{}\left\{0,1\right\}\mathclose{}}} x \cdot\mathbb{P}(X=x) && \text{(range of Bernoulli r.v. is } \{0, 1\} \text{)} \\&= \mathopen{}\left(0 \cdot\mathbb{P}(X=0)\right)\mathclose{} + \mathopen{}\left(1 \cdot\mathbb{P}(X=1)\right)\mathclose{} && \text{(expand sum over } x = 0 \text{ and } x = 1 \text{)} \\&= \mathopen{}\left(0 \cdot(1-\pi)\right)\mathclose{} + \mathopen{}\left(1 \cdot\pi\right)\mathclose{} && \text{(substitute Bernoulli PMF values)} \\&= 0 + \pi&& \text{(multiplication by 0 and 1)} \\&= \pi&& \text{(addition of 0)} \end{aligned} \]

LemTheorem 2 (Expectation of time-to-event variables)

Theorem 2 (Expectation of time-to-event variables) If \(T\) is a non-negative random variable with survival function \(\operatorname{S}(t)\) and a defined expectation, then:

\[{\mathbb{E}\mathopen{}\left[T\right]\mathclose{}} = \int_{t=0}^{\infty} \operatorname{S}(t)\,dt\]

ProofProof

Proof. We prove the continuous case, in which \(T\) has a density \(\operatorname{f}\). The integrand \(\operatorname{f}(u) \cdot{\mathbb{1}\mathopen{}\left(0 \le t \le u\right)\mathclose{}}\) is non-negative on \([0, \infty) \times [0, \infty)\), so Tonelli’s theorem (the non-negative case of the Fubini–Tonelli theorem; Billingsley [2], Theorem 18.3) lets us exchange the order of integration:

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[T\right]\mathclose{}} &= \int_{u=0}^{\infty} u\,\operatorname{f}(u)\,du && \text{(definition of expectation; } T \ge 0 \text{)}\\ &= \int_{u=0}^{\infty}\mathopen{}\left(\int_{t=0}^{u} 1\,dt\right)\mathclose{}\operatorname{f}(u)\,du && \text{(} u = \textstyle\int_0^u 1\,dt \text{)}\\ &= \int_{u=0}^{\infty}\int_{t=0}^{u} \operatorname{f}(u)\,dt\,du && \text{(move } \operatorname{f}(u) \text{ inside the inner integral)}\\ &= \int_{t=0}^{\infty}\int_{u=t}^{\infty} \operatorname{f}(u)\,du\,dt && \text{(Tonelli: exchange the order over } 0 \le t \le u \text{)}\\ &= \int_{t=0}^{\infty}\Pr(T>t)\,dt && \text{(integrate the density over } (t, \infty) \text{)}\\ &= \int_{t=0}^{\infty}\operatorname{S}(t)\,dt && \text{(definition of the survival function)} \end{aligned} \]

Every step also holds when \(\int_{u=0}^{\infty} u\,\operatorname{f}(u)\,du\) is infinite, because Tonelli’s theorem needs only a non-negative integrand; so \(\int_{t=0}^{\infty} \operatorname{S}(t)\,dt\) is finite exactly when \({\mathbb{E}\mathopen{}\left[T\right]\mathclose{}}\) is defined.

See [3] for an alternative presentation of this proof.

ExmExample 3 (Mean of an exponential random variable via survival function)

Example 3 (Mean of an exponential random variable via survival function) Let \(T\) be exponential with rate \({\lambda}> 0\), so \(\operatorname{S}(t) = \text{e}^{-{\lambda}t}\) for \(t \ge 0\), as computed on the random variables page. By Theorem 2:

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[T\right]\mathclose{}} &= \int_0^\infty \operatorname{S}(t)\,dt && \text{(expectation via the survival function)}\\ &= \int_0^\infty \text{e}^{-{\lambda}t}\,dt && \text{(substitute the survival function)}\\ &= \mathopen{}\left[-\frac{1}{{\lambda}}\text{e}^{-{\lambda}t}\right]\mathclose{}_0^\infty && \text{(antiderivative)}\\ &= 0 - \mathopen{}\left(-\frac{1}{{\lambda}}\right)\mathclose{} && \text{(evaluate at the bounds)}\\ &= \frac{1}{{\lambda}} && \text{(simplify)} \end{aligned} \]

DefDefinition 2 (Expectation of a random matrix)

Definition 2 (Expectation of a random matrix) For a random matrix \(\mathbf{A}\) of size \(m \times n\) with \((i,j)\)-th element \(A_{ij}\), the expectation \(\mathbb{E}\mathbf{A}\) is the \(m \times n\) matrix whose \((i,j)\)-th element is \({\mathbb{E}\mathopen{}\left[A_{ij}\right]\mathclose{}}\):

\[ \mathbb{E}\mathbf{A} \stackrel{\text{def}}{=}\begin{pmatrix} {\mathbb{E}\mathopen{}\left[A_{11}\right]\mathclose{}} & {\mathbb{E}\mathopen{}\left[A_{12}\right]\mathclose{}} & \cdots & {\mathbb{E}\mathopen{}\left[A_{1n}\right]\mathclose{}} \\ {\mathbb{E}\mathopen{}\left[A_{21}\right]\mathclose{}} & {\mathbb{E}\mathopen{}\left[A_{22}\right]\mathclose{}} & \cdots & {\mathbb{E}\mathopen{}\left[A_{2n}\right]\mathclose{}} \\ \vdots & \vdots & \ddots & \vdots \\ {\mathbb{E}\mathopen{}\left[A_{m1}\right]\mathclose{}} & {\mathbb{E}\mathopen{}\left[A_{m2}\right]\mathclose{}} & \cdots & {\mathbb{E}\mathopen{}\left[A_{mn}\right]\mathclose{}} \end{pmatrix} \]

RemarkRemark

Remark. In other words, expectation is applied element-wise to a random matrix.

ExmExample 4 (Expectation of a random vector of coin flips)

Example 4 (Expectation of a random vector of coin flips) For the two fair coin flips in the independence page’s example, the random vector \(\mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{X}}\vphantom{X}}= {(X_1, X_2)}^{\top}\) is a \(2 \times 1\) random matrix, and:

\[\mathbb{E}\mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{X}}\vphantom{X}}= \begin{pmatrix}{\mathbb{E}\mathopen{}\left[X_1\right]\mathclose{}} \\ {\mathbb{E}\mathopen{}\left[X_2\right]\mathclose{}}\end{pmatrix} = \begin{pmatrix}1/2 \\ 1/2\end{pmatrix}\]

since each \(X_i\) is Bernoulli with \(\pi= 1/2\) (Theorem 1).

LemTheorem 3 (Law of the Unconscious Statistician (LOTUS))

Theorem 3 (Law of the Unconscious Statistician (LOTUS)) Discrete case. For any function \(g\) of a discrete random variable \(X\) [4]:

\[{\mathbb{E}\mathopen{}\left[g(X)\right]\mathclose{}} = \sum_{x \in \mathcal{R}(X)} g(x) \cdot\mathbb{P}(X=x)\]

Continuous case. For any function \(g\) of a continuous random variable \(X\) with density \(\operatorname{p}(X=x)\):

\[{\mathbb{E}\mathopen{}\left[g(X)\right]\mathclose{}} = \int_{x \in \mathcal{R}(X)} g(x) \cdot\operatorname{p}(X=x)\, dx\]

ProofProof

Proof. We prove the discrete case. Let \(Y = g(X)\). For each \(y \in \mathcal{R}(Y)\), the event \(\{Y = y\}\) is the disjoint union of the events \(\{X = x\}\) over the values \(x\) with \(g(x) = y\), and each \(x \in \mathcal{R}(X)\) belongs to exactly one such group.

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[g(X)\right]\mathclose{}} &= {\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} && \text{(substitution } Y = g(X) \text{)} \\&= \sum_{y \in \mathcal{R}(Y)} y \cdot\mathbb{P}(Y=y) && \text{(definition of expectation for discrete r.v.)} \\&= \sum_{y \in \mathcal{R}(Y)} y \cdot\sum_{\substack{x \in \mathcal{R}(X) \\ g(x) = y}} \mathbb{P}(X=x) && \text{(countable additivity over the disjoint events } \{X = x\} \text{)} \\&= \sum_{y \in \mathcal{R}(Y)} \sum_{\substack{x \in \mathcal{R}(X) \\ g(x) = y}} y \cdot\mathbb{P}(X=x) && \text{(distribute } y \text{ into the inner sum)} \\&= \sum_{y \in \mathcal{R}(Y)} \sum_{\substack{x \in \mathcal{R}(X) \\ g(x) = y}} g(x) \cdot\mathbb{P}(X=x) && \text{(} y = g(x) \text{ for every term of the inner sum)} \\&= \sum_{x \in \mathcal{R}(X)} g(x) \cdot\mathbb{P}(X=x) && \text{(the groups partition } \mathcal{R}(X) \text{)} \end{aligned} \]

The last step regroups a possibly infinite sum, which is valid because \({\mathbb{E}\mathopen{}\left[g(X)\right]\mathclose{}}\) is defined only when the sum converges absolutely.

RemarkRemark

Remark. LOTUS says that to compute \({\mathbb{E}\mathopen{}\left[g(X)\right]\mathclose{}}\), we do not need to first find the distribution of \(g(X)\); we can compute the expectation directly using the distribution of \(X\). The continuous case is the density-weighted analogue of this argument, but a fully rigorous proof needs the general change-of-variables theorem for integrals against a pushforward measure — approximating \(g\) by simple functions and passing to the limit — which is beyond this page’s scope [2], [5], [6], [7].

ExmExample 5 (Expected value of \(X^2\) for a Bernoulli variable)

Example 5 (Expected value of \(X^2\) for a Bernoulli variable) Let \(X \sim \operatorname{Ber}(\pi)\). By LOTUS (Theorem 3, discrete case):

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[X^2\right]\mathclose{}} &= \sum_{x \in {\mathopen{}\left\{0,1\right\}\mathclose{}}} x^2 \cdot\mathbb{P}(X=x) && \text{(LOTUS, discrete case)} \\ &= 0^2 \cdot\mathbb{P}(X=0) + 1^2 \cdot\mathbb{P}(X=1) && \text{(expand sum over } x = 0 \text{ and } x = 1 \text{)} \\ &= 0^2 \cdot(1-\pi) + 1^2 \cdot\pi && \text{(substitute Bernoulli PMF values)} \\ &= 0 + \pi && \text{(simplify each term)} \\ &= \pi && \text{(add)} \end{aligned} \]

ExmExample 6 (Expected value of \(X^2\) for a Uniform(0,1) variable)

Example 6 (Expected value of \(X^2\) for a Uniform(0,1) variable) Let \(X \sim \text{Uniform}(0,1)\) (uniform distribution), so \(\operatorname{p}(X=x) = 1\) for \(x \in [0,1]\). By LOTUS (Theorem 3, continuous case):

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[X^2\right]\mathclose{}} &= \int_0^1 x^2 \cdot\operatorname{p}(X=x)\,dx && \text{(LOTUS, continuous case)} \\&= \int_0^1 x^2 \cdot 1\,dx && \text{(}\operatorname{p}(X=x) = 1\text{ on } [0,1]\text{)} \\&= \mathopen{}\left[\frac{x^3}{3}\right]\mathclose{}_0^1 && \text{(antiderivative of } x^2\text{)} \\&= \frac{1}{3}. && \text{(evaluate at the bounds)} \end{aligned} \]

LemTheorem 4 (Linearity of expectation)

Theorem 4 (Linearity of expectation) For random variables \(X\) and \(Y\) with defined expectations, and constants \(a\), \(b\), and \(c\):

\[{\mathbb{E}\mathopen{}\left[aX + bY + c\right]\mathclose{}} = a{\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} + b{\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} + c\]

ProofProof

Proof. We prove the discrete case, applying Theorem 3 to the pair \((X, Y)\), which is a single discrete random object with values \((x, y)\), and \(g(x, y) = ax + by + c\):

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[aX + bY + c\right]\mathclose{}} &= \sum_{x \in \mathcal{R}(X)}\sum_{y \in \mathcal{R}(Y)} (ax + by + c) \cdot\mathbb{P}(X=x, Y=y) && \text{(LOTUS for the pair } (X, Y) \text{)}\\ &= a\sum_{x \in \mathcal{R}(X)}\sum_{y \in \mathcal{R}(Y)} x \cdot\mathbb{P}(X=x, Y=y) + b\sum_{x \in \mathcal{R}(X)}\sum_{y \in \mathcal{R}(Y)} y \cdot\mathbb{P}(X=x, Y=y) + c\sum_{x \in \mathcal{R}(X)}\sum_{y \in \mathcal{R}(Y)} \mathbb{P}(X=x, Y=y) && \text{(distribute the sum over the terms; constants factor out)}\\ &= a\sum_{x \in \mathcal{R}(X)}\sum_{y \in \mathcal{R}(Y)} x \cdot\mathbb{P}(X=x, Y=y) + b\sum_{y \in \mathcal{R}(Y)}\sum_{x \in \mathcal{R}(X)} y \cdot\mathbb{P}(X=x, Y=y) + c\sum_{x \in \mathcal{R}(X)}\sum_{y \in \mathcal{R}(Y)} \mathbb{P}(X=x, Y=y) && \text{(exchange the order of summation in the second term)}\\ &= a\sum_{x \in \mathcal{R}(X)} x \sum_{y \in \mathcal{R}(Y)} \mathbb{P}(X=x, Y=y) + b\sum_{y \in \mathcal{R}(Y)} y \sum_{x \in \mathcal{R}(X)} \mathbb{P}(X=x, Y=y) + c \cdot 1 && \text{(factor } x \text{ and } y \text{ out of the inner sums; total probability is 1)}\\ &= a\sum_{x \in \mathcal{R}(X)} x \cdot\mathbb{P}(X=x) + b\sum_{y \in \mathcal{R}(Y)} y \cdot\mathbb{P}(Y=y) + c && \text{(marginalize: countable additivity)}\\ &= a{\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} + b{\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} + c && \text{(definition of expectation)} \end{aligned} \]

Splitting and exchanging the sums is valid because the sums converge absolutely, since \(\mathopen{}\left|ax + by + c\right|\mathclose{} \le \mathopen{}\left|a\right|\mathclose{}\mathopen{}\left|x\right|\mathclose{} + \mathopen{}\left|b\right|\mathclose{}\mathopen{}\left|y\right|\mathclose{} + \mathopen{}\left|c\right|\mathclose{}\) and \({\mathbb{E}\mathopen{}\left[X\right]\mathclose{}}\) and \({\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}}\) are defined.

Beyond the discrete case, this proof does not carry over by replacing sums with integrals. That replacement would need a joint density for \((X, Y)\), and some pairs have none: if \(X\) is continuous, the pair \((X, X)\) has no joint density. In general, expectation is an integral against the probability measure, and the theorem is the linearity of that (Lebesgue) integral [2], which is beyond these notes’ scope.

ExmExample 7 (Expected total of two dice)

Example 7 (Expected total of two dice) Let \(X\) and \(Y\) be the results of two six-sided die rolls. Each has expectation

\[ \begin{aligned} \sum_{x=1}^{6} x \cdot\tfrac{1}{6} &= \tfrac{21}{6} \\ &= 3.5, \end{aligned} \]

so:

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[X + Y\right]\mathclose{}} &= {\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} + {\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} && \text{(linearity of expectation with } a = 1, b = 1, c = 0 \text{)}\\ &= 3.5 + 3.5 && \text{(substitute)}\\ &= 7 && \text{(add)} \end{aligned} \]

This calculation does not need the rolls to be independent.

CorCorollary 1 (Expectation of a linear function of one random variable)

Corollary 1 (Expectation of a linear function of one random variable) For a random variable \(X\) with a defined expectation, and constants \(a\) and \(c\):

\[{\mathbb{E}\mathopen{}\left[aX + c\right]\mathclose{}} = a{\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} + c\]

ProofProof

Proof. For discrete \(X\), this identity is Theorem 4 with \(b = 0\). For continuous \(X\) with density \(\operatorname{p}(X=x)\), apply Theorem 3 with \(g(x) = ax + c\):

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[aX + c\right]\mathclose{}} &= \int_{x \in \mathcal{R}(X)} (ax + c) \cdot\operatorname{p}(X=x)\,dx && \text{(LOTUS, continuous case)} \\ &= a\int_{x \in \mathcal{R}(X)} x \cdot\operatorname{p}(X=x)\,dx + c\int_{x \in \mathcal{R}(X)} \operatorname{p}(X=x)\,dx && \text{(linearity of the integral)} \\ &= a{\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} + c\int_{x \in \mathcal{R}(X)} \operatorname{p}(X=x)\,dx && \text{(definition of expectation)} \\ &= a{\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} + c \cdot 1 && \text{(a density integrates to 1)} \\ &= a{\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} + c && \text{(simplify)} \end{aligned} \]

Splitting the integral is valid because both pieces converge absolutely: the first because \({\mathbb{E}\mathopen{}\left[X\right]\mathclose{}}\) is defined, and the second because its integrand is a non-negative density.

ExmExample 8 (Expectation of a rescaled uniform variable)

Example 8 (Expectation of a rescaled uniform variable) Let \(X \sim \text{Uniform}(0,1)\), so

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} &= \int_0^1 x\,dx \\ &= \tfrac{1}{2}. \end{aligned} \]

By Corollary 1 with \(a = 2\) and \(c = 1\):

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[2X + 1\right]\mathclose{}} &= 2{\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} + 1 && \text{(expectation of a linear function)} \\ &= 2 \cdot\tfrac{1}{2} + 1 && \text{(substitute } {\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} = \tfrac{1}{2} \text{)} \\ &= 2 && \text{(evaluate)} \end{aligned} \]

LemLemma 1 (Linearity of expectation for finite sums)

Lemma 1 (Linearity of expectation for finite sums) For random variables \(X_1, \ldots, X_n\) with defined expectations, and constants \(a_1, \ldots, a_n\):

\[{\mathbb{E}\mathopen{}\left[\sum_{i=1}^na_i X_i\right]\mathclose{}} = \sum_{i=1}^na_i {\mathbb{E}\mathopen{}\left[X_i\right]\mathclose{}}\]

ProofProof

Proof. Prove this by induction on \(n\), applying linearity of expectation for two variables in each step.

For \(n = 1\):

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[a_1 X_1\right]\mathclose{}} &= {\mathbb{E}\mathopen{}\left[a_1 X_1 + 0 \cdot X_1\right]\mathclose{}} && \text{(} 0 \cdot X_1 = 0 \text{)} \\ &= {\mathbb{E}\mathopen{}\left[a_1 X_1 + 0 \cdot X_1 + 0\right]\mathclose{}} && \text{(} v + 0 = v \text{)} \\ &= a_1 {\mathbb{E}\mathopen{}\left[X_1\right]\mathclose{}} + 0 \cdot{\mathbb{E}\mathopen{}\left[X_1\right]\mathclose{}} + 0 && \text{(linearity of expectation, } a = a_1, b = 0, c = 0 \text{)} \\ &= a_1 {\mathbb{E}\mathopen{}\left[X_1\right]\mathclose{}} + 0 && \text{(} 0 \cdot v = 0 \text{)} \\ &= a_1 {\mathbb{E}\mathopen{}\left[X_1\right]\mathclose{}} && \text{(} v + 0 = v \text{)} \end{aligned} \]

For the inductive step, assume the lemma holds for \(n - 1\) variables, and let \(W \stackrel{\text{def}}{=}\sum_{i=1}^{n-1} a_i X_i\):

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[\sum_{i=1}^na_i X_i\right]\mathclose{}} &= {\mathbb{E}\mathopen{}\left[W + a_n X_n\right]\mathclose{}} && \text{(split off the last term)} \\ &= {\mathbb{E}\mathopen{}\left[1 \cdot W + a_n X_n\right]\mathclose{}} && \text{(} 1 \cdot W = W \text{)} \\ &= {\mathbb{E}\mathopen{}\left[1 \cdot W + a_n X_n + 0\right]\mathclose{}} && \text{(} v + 0 = v \text{)} \\ &= 1 \cdot{\mathbb{E}\mathopen{}\left[W\right]\mathclose{}} + a_n {\mathbb{E}\mathopen{}\left[X_n\right]\mathclose{}} + 0 && \text{(linearity of expectation, } a = 1, b = a_n, c = 0 \text{)} \\ &= {\mathbb{E}\mathopen{}\left[W\right]\mathclose{}} + a_n {\mathbb{E}\mathopen{}\left[X_n\right]\mathclose{}} + 0 && \text{(} 1 \cdot v = v \text{)} \\ &= {\mathbb{E}\mathopen{}\left[W\right]\mathclose{}} + a_n {\mathbb{E}\mathopen{}\left[X_n\right]\mathclose{}} && \text{(} v + 0 = v \text{)} \\ &= \sum_{i=1}^{n-1} a_i {\mathbb{E}\mathopen{}\left[X_i\right]\mathclose{}} + a_n {\mathbb{E}\mathopen{}\left[X_n\right]\mathclose{}} && \text{(inductive hypothesis)} \\ &= \sum_{i=1}^na_i {\mathbb{E}\mathopen{}\left[X_i\right]\mathclose{}} && \text{(include the last term in the sum)} \end{aligned} \]

ExmExample 9 (Expected total of five dice)

Example 9 (Expected total of five dice) Let \(X_1, \ldots, X_5\) be the outcomes of five rolls of a fair die. Each roll has expectation \({\mathbb{E}\mathopen{}\left[X_i\right]\mathclose{}} = 3.5\). Applying Lemma 1 with every \(a_i = 1\) gives the expected total:

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[\sum_{i=1}^5 X_i\right]\mathclose{}} &= \sum_{i=1}^5 {\mathbb{E}\mathopen{}\left[X_i\right]\mathclose{}} && \text{(linearity of expectation for finite sums)} \\ &= 5 \cdot 3.5 && \text{(each roll has expectation } 3.5 \text{)} \\ &= 17.5 && \text{(multiply)} \end{aligned} \]

ExrExercise 1 (Why the sample mean is a random variable)

Exercise 1 (Why the sample mean is a random variable) Let \(X_1, \ldots, X_n\) be independent draws from the same distribution, each with population mean \(\mu\) and variance \(\sigma^2\), and let \(\bar X = \frac{1}{n}\sum_{i=1}^nX_i\) be their sample mean.

Use Theorem 4 to show that \(\mathbb{E}[\bar X] = \mu\), and say in one sentence what that does not tell us.

SolutionSolution 1

Solution 1. Pull the constant \(1/n\) out and distribute the sum over the terms, both by Theorem 4:

\[ \begin{aligned} \mathbb{E}[\bar X] &= \mathbb{E}\mathopen{}\left[\frac{1}{n}\sum_{i=1}^nX_i\right]\mathclose{} \\ &= \frac{1}{n}\sum_{i=1}^n\mathbb{E}[X_i] \\ &= \frac{1}{n}\,(n\mu) \\ &= \mu \end{aligned} \]

So the sample mean is right on average. Independence was never used: Theorem 4 holds regardless, so this much would be true even for draws that influence one another.

What it does not tell us is how far any particular sample mean falls from \(\mu\) — that is a statement about variance, not expectation, and it is where independence does the work. The distinction matters because an estimator or fitted model is a function of one particular sample. Knowing that the procedure is right on average says nothing about the estimate actually in front of you, and separating those two statements is foundational to understanding bias and variance.

LemTheorem 5 (The expectation of a sample mean)

Theorem 5 (The expectation of a sample mean) Let \(X_1, \ldots, X_n\) be random variables, with \(n \ge 1\), that each have finite population mean \(\mu\), and let \(\bar X \stackrel{\text{def}}{=}\frac{1}{n}\sum_{i=1}^nX_i\). The \(X_i\) need not be independent. Then

\[\mathbb{E}[\bar X] = \mu\]

ProofProof

Proof. This is the solution to Exercise 1, worked in Solution 1. It follows from Theorem 4, which needs no independence and applies because each \(\mathbb{E}[X_i] = \mu\) is finite.

\[ \operatorname{p}(X=x,\,Y=y) = \frac{1}{2\pi\sigma_X\sigma_Y\sqrt{1-\rho^2}} \text{e}^{-\frac{1}{2(1-\rho^2)} \mathopen{}\left[\frac{(x-\mu_X)^2}{\sigma^2_X} - \frac{2\rho(x-\mu_X)(y-\mu_Y)}{\sigma_X\sigma_Y} + \frac{(y-\mu_Y)^2}{\sigma^2_Y}\right]\mathclose{}} \]

A further standard fact about the bivariate normal (Casella and Berger [6]) is that the marginal distribution of \(X\) is normal, \(X \sim {\operatorname{N}\mathopen{}\left(\mu_X, \sigma^2_X\right)\mathclose{}}\). At \(x = 40\) weeks (a full-term pregnancy), \(\mu_X = 38.5417\) and \(\sigma_X = 1.8173\), so:

\[ \begin{aligned} \operatorname{p}(X=40) &= \frac{1}{\sigma_X\sqrt{2\pi}} \text{e}^{-\frac{(40-\mu_X)^2}{2\sigma^2_X}} && \text{(normal density at } x = 40 \text{)} \\&= \frac{1}{1.8173\sqrt{2\pi}} \text{e}^{-\frac{(40-38.5417)^2}{2(1.8173)^2}} && \text{(substitute } \mu_X \text{ and } \sigma_X \text{)} \\&\approx 0.1591 && \text{(evaluate)} \end{aligned} \]

By Definition 4, dividing the joint density by this marginal density and simplifying the exponent (completing the square in \(y\); Casella and Berger [6]) gives the conditional PDF of \(Y\) given \(X = 40\), which is itself normal with mean shifted along the regression line and variance reduced by a factor of \(1-\rho^2\):

\[ \begin{aligned} \operatorname{p}(Y=y \mid X=40) &= \frac{\operatorname{p}(X=40,\,Y=y)}{\operatorname{p}(X=40)} && \text{(definition of the conditional PDF)} \\&= \frac{1}{\sigma_Y\sqrt{2\pi(1-\rho^2)}} \text{e}^{-\frac{1}{2(1-\rho^2)}\mathopen{}\left[\frac{(40-\mu_X)^2}{\sigma^2_X} - \frac{2\rho(40-\mu_X)(y-\mu_Y)}{\sigma_X\sigma_Y} + \frac{(y-\mu_Y)^2}{\sigma^2_Y}\right]\mathclose{} + \frac{(40-\mu_X)^2}{2\sigma^2_X}} && \text{(substitute both densities; combine prefactors and exponents)} \\&= \frac{1}{\sigma_Y\sqrt{2\pi(1-\rho^2)}} \text{e}^{-\frac{\rho^2(40-\mu_X)^2}{2\sigma^2_X(1-\rho^2)} + \frac{\rho(40-\mu_X)(y-\mu_Y)}{\sigma_X\sigma_Y(1-\rho^2)} - \frac{(y-\mu_Y)^2}{2\sigma^2_Y(1-\rho^2)}} && \text{(combine the } (40-\mu_X)^2 \text{ terms: } 1 - \tfrac{1}{1-\rho^2} = \tfrac{-\rho^2}{1-\rho^2} \text{)} \\&= \frac{1}{\sigma_Y\sqrt{2\pi(1-\rho^2)}} \text{e}^{-\frac{1}{2\sigma^2_Y(1-\rho^2)} \mathopen{}\left[\rho^2\frac{\sigma^2_Y}{\sigma^2_X}(40-\mu_X)^2 - 2\rho\frac{\sigma_Y}{\sigma_X}(40-\mu_X)(y-\mu_Y) + (y-\mu_Y)^2\right]\mathclose{}} && \text{(factor } -\tfrac{1}{2\sigma^2_Y(1-\rho^2)} \text{ out of the exponent)} \\&= \frac{1}{\sigma_Y\sqrt{2\pi(1-\rho^2)}} \text{e}^{-\frac{\mathopen{}\left(y - \mathopen{}\left[\mu_Y + \rho\frac{\sigma_Y}{\sigma_X}(40-\mu_X)\right]\mathclose{}\right)\mathclose{}^2}{2\sigma_Y^2(1-\rho^2)}} && \text{(the bracket is a perfect square in } y \text{)} \end{aligned} \]

Multiplying out each of the last two exponents reproduces the one before it.

DefDefinition 8 (Conditional expectation of a function of \(X\) and \(Y\))

Definition 8 (Conditional expectation of a function of \(X\) and \(Y\)) Let \(X\) and \(Y\) be jointly distributed random variables, \(h\) a function of two arguments, and \(x\) a value at which the conditional PMF or PDF of \(Y\) given \(X = x\) is defined (Definition 3, Definition 4, or Definition 6). \[{\mathbb{E}\mathopen{}\left[h(X, Y) \mid X = x\right]\mathclose{}} \stackrel{\text{def}}{=}\sum_{y \in \mathcal{R}(Y)} h(x, y) \cdot\mathbb{P}(Y = y \mid X = x)\]

and for continuous \(Y\):

\[{\mathbb{E}\mathopen{}\left[h(X, Y) \mid X = x\right]\mathclose{}} \stackrel{\text{def}}{=}\int_{y \in \mathcal{R}(Y)} h(x, y) \cdot\operatorname{p}(Y = y \mid X = x)\,dy\]

when the sum or integral converges absolutely. Evaluating this function of \(x\) at \(X\) gives the random variable \({\mathbb{E}\mathopen{}\left[h(X, Y) \mid X\right]\mathclose{}}\).

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[(Y - X)^2 \mid X = 1\right]\mathclose{}} &= (1 - 1)^2 \cdot\tfrac{1}{2} + (2 - 1)^2 \cdot\tfrac{1}{2} && \text{(definition, with } x = 1 \text{)} \\ &= 0 + \tfrac{1}{2} && \text{(evaluate each term)} \\ &= \tfrac{1}{2} && \text{(add)} \end{aligned} \]

Corollary 2 (With \(h(x, y) = y\), the general definition gives \({{\mathbb{E}\mathopen{}\left[Y \mid X = x\right]\mathclose{}}}\)) For jointly distributed \(X\) and \(Y\) and \(h(x, y) = y\), Definition 8 gives the conditional expectation of \(Y\) given \(X = x\) from Definition 5 (when \(X\) and \(Y\) are both discrete or both continuous) or from Definition 6 (when one is discrete and the other continuous):

\[{\mathbb{E}\mathopen{}\left[h(X, Y) \mid X = x\right]\mathclose{}} = {\mathbb{E}\mathopen{}\left[Y \mid X = x\right]\mathclose{}}\]

ProofProof

Proof. For discrete \(Y\):

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[h(X, Y) \mid X = x\right]\mathclose{}} &= \sum_{y \in \mathcal{R}(Y)} h(x, y) \cdot\mathbb{P}(Y = y \mid X = x) && \text{(conditional expectation of a function, discrete } Y \text{)} \\ &= \sum_{y \in \mathcal{R}(Y)} y \cdot\mathbb{P}(Y = y \mid X = x) && \text{(} h(x, y) = y \text{)} \\ &= {\mathbb{E}\mathopen{}\left[Y \mid X = x\right]\mathclose{}} && \text{(conditional expectation, discrete } Y \text{)} \end{aligned} \]

The last step is Definition 5 when \(X\) is discrete and Definition 6 when \(X\) is continuous. For continuous \(Y\), the same steps hold with integrals over \(y\) in place of the sums and \(\operatorname{p}(Y = y \mid X = x)\) in place of \(\mathbb{P}(Y = y \mid X = x)\).

LemTheorem 6 (Conditional LOTUS, discrete case)

Theorem 6 (Conditional LOTUS, discrete case) Let \(X\) and \(Y\) be jointly distributed discrete random variables, \(h\) a function of two arguments, \(W \stackrel{\text{def}}{=}h(X, Y)\), and \(x\) a value with \(\mathbb{P}(X = x) > 0\). Then \(W\) is discrete, and \({\mathbb{E}\mathopen{}\left[h(X, Y) \mid X = x\right]\mathclose{}}\) from Definition 8 equals \({\mathbb{E}\mathopen{}\left[W \mid X = x\right]\mathclose{}}\) from Definition 5, with one sum converging absolutely exactly when the other does.

ProofProof

Proof. \(W\) is discrete because its range is contained in \({\mathopen{}\left\{h(u, y) : u \in \mathcal{R}(X),\, y \in \mathcal{R}(Y)\right\}\mathclose{}}\), which is countable. For each \(w \in \mathcal{R}(W)\), the event \({\mathopen{}\left\{X = x,\, W = w\right\}\mathclose{}}\) is the disjoint union of the events \({\mathopen{}\left\{X = x,\, Y = y\right\}\mathclose{}}\) over the values \(y \in \mathcal{R}(Y)\) with \(h(x, y) = w\), so:

\[ \begin{aligned} \mathbb{P}(W = w \mid X = x) &= \frac{\mathbb{P}(X = x,\, W = w)}{\mathbb{P}(X = x)} && \text{(conditional PMF of } W \text{)} \\ &= \frac{1}{\mathbb{P}(X = x)} \sum_{\substack{y \in \mathcal{R}(Y) \\ h(x, y) = w}} \mathbb{P}(X = x,\, Y = y) && \text{(countable additivity over the disjoint events } {\mathopen{}\left\{X = x,\, Y = y\right\}\mathclose{}} \text{)} \\ &= \sum_{\substack{y \in \mathcal{R}(Y) \\ h(x, y) = w}} \mathbb{P}(Y = y \mid X = x) && \text{(divide each term; conditional PMF of } Y \text{)} \end{aligned} \]

Every \(y \in \mathcal{R}(Y)\) with \(\mathbb{P}(Y = y \mid X = x) > 0\) has \(h(x, y) \in \mathcal{R}(W)\), because some outcome has \(X = x\) and \(Y = y\), and \(W = h(x, y)\) there; the other values of \(y\) contribute terms equal to \(0\). So the groups \({\mathopen{}\left\{y \in \mathcal{R}(Y) : h(x, y) = w\right\}\mathclose{}}\), over \(w \in \mathcal{R}(W)\), contain every \(y\) with a non-zero term, each exactly once:

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[W \mid X = x\right]\mathclose{}} &= \sum_{w \in \mathcal{R}(W)} w \cdot\mathbb{P}(W = w \mid X = x) && \text{(conditional expectation of } W \text{)} \\ &= \sum_{w \in \mathcal{R}(W)} w \cdot\sum_{\substack{y \in \mathcal{R}(Y) \\ h(x, y) = w}} \mathbb{P}(Y = y \mid X = x) && \text{(the display above)} \\ &= \sum_{w \in \mathcal{R}(W)} \sum_{\substack{y \in \mathcal{R}(Y) \\ h(x, y) = w}} w \cdot\mathbb{P}(Y = y \mid X = x) && \text{(distribute } w \text{ into the inner sum)} \\ &= \sum_{w \in \mathcal{R}(W)} \sum_{\substack{y \in \mathcal{R}(Y) \\ h(x, y) = w}} h(x, y) \cdot\mathbb{P}(Y = y \mid X = x) && \text{(} w = h(x, y) \text{ for every term of the inner sum)} \\ &= \sum_{y \in \mathcal{R}(Y)} h(x, y) \cdot\mathbb{P}(Y = y \mid X = x) && \text{(the groups contain every non-zero term once)} \\ &= {\mathbb{E}\mathopen{}\left[h(X, Y) \mid X = x\right]\mathclose{}} && \text{(conditional expectation of a function of } X \text{ and } Y \text{)} \end{aligned} \]

The same steps with \(\mathopen{}\left|w\right|\mathclose{}\) and \(\mathopen{}\left|h(x, y)\right|\mathclose{}\) in place of \(w\) and \(h(x, y)\) regroup a sum of non-negative terms, which is valid whether or not it converges, so one sum converges absolutely exactly when the other does, and then the regrouping above is valid too.

RemarkRemark

Remark. Definition 8 is the conditional version of LOTUS: for discrete \(X\), it is LOTUS applied under the probability measure \(\Pr(\cdot \mid X = x)\), and by Theorem 6, results about \({\mathbb{E}\mathopen{}\left[W \mid X\right]\mathclose{}}\) apply to it. \(Y\) can also be a pair \((Y, Z)\), with the sum or integral taken over both.

LemTheorem 7 (Linearity of conditional expectation)

Theorem 7 (Linearity of conditional expectation) For jointly distributed \(X\) and \(Y\), functions \(h_1\) and \(h_2\) whose conditional expectations given \(X = x\) are defined, and constants \(a\) and \(b\):

\[{\mathbb{E}\mathopen{}\left[a h_1(X, Y) + b h_2(X, Y) \mid X = x\right]\mathclose{}} = a{\mathbb{E}\mathopen{}\left[h_1(X, Y) \mid X = x\right]\mathclose{}} + b{\mathbb{E}\mathopen{}\left[h_2(X, Y) \mid X = x\right]\mathclose{}}\]

Evaluating both sides at \(X\) gives \({\mathbb{E}\mathopen{}\left[a h_1(X, Y) + b h_2(X, Y) \mid X\right]\mathclose{}} = a{\mathbb{E}\mathopen{}\left[h_1(X, Y) \mid X\right]\mathclose{}} + b{\mathbb{E}\mathopen{}\left[h_2(X, Y) \mid X\right]\mathclose{}}\).

ProofProof

Proof. For discrete \(Y\):

\[ \begin{aligned} &{\mathbb{E}\mathopen{}\left[a h_1(X, Y) + b h_2(X, Y) \mid X = x\right]\mathclose{}} \\&= \sum_{y \in \mathcal{R}(Y)} \mathopen{}\left(a h_1(x, y) + b h_2(x, y)\right)\mathclose{} \cdot\mathbb{P}(Y = y \mid X = x) && \text{(definition of conditional expectation)} \\ &= a \sum_{y \in \mathcal{R}(Y)} h_1(x, y) \cdot\mathbb{P}(Y = y \mid X = x) + b \sum_{y \in \mathcal{R}(Y)} h_2(x, y) \cdot\mathbb{P}(Y = y \mid X = x) && \text{(distribute the sum over the terms; factor out the constants)} \\ &= a{\mathbb{E}\mathopen{}\left[h_1(X, Y) \mid X = x\right]\mathclose{}} + b{\mathbb{E}\mathopen{}\left[h_2(X, Y) \mid X = x\right]\mathclose{}} && \text{(definition of conditional expectation)} \end{aligned} \]

Splitting the sum is valid because both sums converge absolutely. For continuous \(Y\), the same steps hold with integrals over \(y\) in place of the sums, by linearity of the integral: unlike Theorem 4, only one variable, \(y\), is integrated, against one conditional density.

ExmExample 16 (Linearity, given the first flip)

Example 16 (Linearity, given the first flip) Continuing Example 15, given \(X = 1\), \(Y\) is \(1\) or \(2\) with probability \(1/2\) each, so \({\mathbb{E}\mathopen{}\left[Y \mid X = 1\right]\mathclose{}} = 3/2\) and

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[Y^2 \mid X = 1\right]\mathclose{}} &= (1 + 4)/2 \\ &= 5/2. \end{aligned} \]

By Theorem 7 with

\[ \begin{aligned} a &= b \\ &= 1: \end{aligned} \]

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[Y + Y^2 \mid X = 1\right]\mathclose{}} &= {\mathbb{E}\mathopen{}\left[Y \mid X = 1\right]\mathclose{}} + {\mathbb{E}\mathopen{}\left[Y^2 \mid X = 1\right]\mathclose{}} && \text{(linearity of conditional expectation)} \\ &= \tfrac{3}{2} + \tfrac{5}{2} && \text{(substitute)} \\ &= 4 && \text{(add)} \end{aligned} \]

As a check, directly:

\[ \begin{aligned} (1 + 1) \cdot\tfrac{1}{2} + (2 + 4) \cdot\tfrac{1}{2} &= 1 + 3 \\ &= 4. \end{aligned} \]

LemTheorem 8 (A function of \(X\) factors out of a conditional expectation given \(X\))

Theorem 8 (A function of \(X\) factors out of a conditional expectation given \(X\)) For jointly distributed \(X\) and \(Y\), a function \(g\) of one argument, and a function \(h\) of two arguments whose conditional expectation given \(X = x\) is defined:

\[{\mathbb{E}\mathopen{}\left[g(X)\,h(X, Y) \mid X = x\right]\mathclose{}} = g(x) \cdot{\mathbb{E}\mathopen{}\left[h(X, Y) \mid X = x\right]\mathclose{}}\]

Evaluating both sides at \(X\) gives \({\mathbb{E}\mathopen{}\left[g(X)\,h(X, Y) \mid X\right]\mathclose{}} = g(X) \cdot{\mathbb{E}\mathopen{}\left[h(X, Y) \mid X\right]\mathclose{}}\). In particular, taking \(h = 1\) gives \({\mathbb{E}\mathopen{}\left[g(X) \mid X\right]\mathclose{}} = g(X)\).

ProofProof

Proof. For discrete \(Y\):

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[g(X)\,h(X, Y) \mid X = x\right]\mathclose{}} &= \sum_{y \in \mathcal{R}(Y)} g(x)\,h(x, y) \cdot\mathbb{P}(Y = y \mid X = x) && \text{(definition of conditional expectation)} \\ &= g(x) \sum_{y \in \mathcal{R}(Y)} h(x, y) \cdot\mathbb{P}(Y = y \mid X = x) && \text{(} g(x) \text{ does not depend on } y \text{)} \\ &= g(x) \cdot{\mathbb{E}\mathopen{}\left[h(X, Y) \mid X = x\right]\mathclose{}} && \text{(definition of conditional expectation)} \end{aligned} \]

For \(h = 1\), the remaining sum is \(\sum_{y \in \mathcal{R}(Y)} \mathbb{P}(Y = y \mid X = x) = 1\):

\[ \begin{aligned} \sum_{y \in \mathcal{R}(Y)} \mathbb{P}(Y = y \mid X = x) &= \sum_{y \in \mathcal{R}(Y)} \frac{\mathbb{P}(X = x,\, Y = y)}{\mathbb{P}(X = x)} && \text{(definition of the conditional PMF)} \\ &= \frac{\mathbb{P}(X = x)}{\mathbb{P}(X = x)} && \text{(marginal PMF from a joint PMF)} \\ &= 1 && \text{(divide)} \end{aligned} \]

For continuous \(Y\), the same steps hold with integrals over \(y\) in place of the sums; the conditional density integrates to 1 by the marginal density theorem (or, in the mixed case, by the joint density-mass function’s marginal identity).

RemarkRemark

Remark. This result is often summarized as “taking out what is known” (e.g., Ross [10], Section 5.6.4): given \(X = x\), any function of \(X\) is the known constant \(g(x)\).

Exercise 2 (Expectation of a sum, given a joint PMF) Let \((X, Y)\) be discrete with joint probability mass function:

\(Y = 0\) \(Y = 1\)

SolutionSolution

Solution. Treating \((X, Y)\) as a single discrete random object taking one of the four values \((0,0)\), \((0,1)\), \((1,0)\), \((1,1)\), LOTUS (Theorem 3) applied to \(g(x, y) = x + y\) gives directly:

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[X + Y\right]\mathclose{}} &= \sum_{x \in \{0,1\}} \sum_{y \in \{0,1\}} (x + y)\,\mathbb{P}(X = x,\, Y = y) && \text{(LOTUS)} \\ &= (0{+}0)(0.2) + (0{+}1)(0.3) + (1{+}0)(0.1) + (1{+}1)(0.4) && \text{(expand the four terms)} \\ &= 0 + 0.3 + 0.1 + 0.8 && \text{(multiply)} \\ &= 1.2 && \text{(add)} \end{aligned} \]

As a check:

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} &= 0(0.5) + 1(0.5) \\ &= 0.5 \end{aligned} \]

and

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} &= 0(0.3) + 1(0.7) \\ &= 0.7, \end{aligned} \]

so

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[X + Y\right]\mathclose{}} &= {\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} + {\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} \\ &= 1.2 \end{aligned} \]

by linearity of expectation.

0.2 Fubini–Tonelli for expectations

LemTheorem 9 (Fubini–Tonelli theorem, measure-theoretic form)

Theorem 9 (Fubini–Tonelli theorem, measure-theoretic form) Let \(\mu_1\) and \(\mu_2\) be \(\sigma\)-finite measures on \(\sigma\)-algebras of subsets of sets \(S_1\) and \(S_2\), and let \(f\) be a measurable function on \(S_1 \times S_2\). If either

  1. \(f \ge 0\) (Tonelli), or

  2. \(\int_{S_1 \times S_2} \mathopen{}\left|f\right|\mathclose{}\,d(\mu_1 \otimes \mu_2) < \infty\) (Fubini),

then the integral of \(f\) against the product measure \(\mu_1 \otimes \mu_2\) equals both iterated integrals:

\[ \begin{aligned} \int_{S_1 \times S_2} f\,d(\mu_1 \otimes \mu_2) &= \int_{S_1}\mathopen{}\left(\int_{S_2} f(s_1, s_2)\,d\mu_2(s_2)\right)\mathclose{}\,d\mu_1(s_1) \\&= \int_{S_2}\mathopen{}\left(\int_{S_1} f(s_1, s_2)\,d\mu_1(s_1)\right)\mathclose{}\,d\mu_2(s_2). \end{aligned} \]

In case (b), each inner integral is finite except on a set of measure \(0\), which does not affect the outer integral.

RemarkRemark

Remark. For expectations, we use this measure-theoretic form of the Fubini–Tonelli theorem, which lets us exchange the order of integration (or summation) over a product of \(\sigma\)-finite measure spaces, provided the integrand is non-negative (Tonelli) or absolutely integrable (Fubini). Its proof is beyond these notes’ scope [2], Theorem 18.3. Lebesgue measure on the real line and counting measure on a countable set are both \(\sigma\)-finite, which gives the theorem a form stated in terms of a joint distribution.

CorCorollary 3 (Joint-distribution form (without independence; corollary of Fubini–Tonelli))

Corollary 3 (Joint-distribution form (without independence; corollary of Fubini–Tonelli)) Let \((X, Y)\) be jointly distributed random variables whose joint distribution has a density \(f_{X,Y}\) with respect to a product of \(\sigma\)-finite reference measures \(\mu_X \otimes \mu_Y\) on \(\mathcal{R}(X) \times \mathcal{R}(Y)\), and let \(h : \mathcal{R}(X) \times \mathcal{R}(Y) \to \mathbb{R}\) be measurable. If either

  1. \(h(X, Y) \ge 0\) almost surely, or

  2. \({\mathbb{E}\mathopen{}\left[\mathopen{}\left|h(X, Y)\right|\mathclose{}\right]\mathclose{}} < \infty\),

then the expectation of \(h(X, Y)\) can be written as an iterated integral against \(f_{X,Y}\), with the order of integration exchangeable:

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[h(X, Y)\right]\mathclose{}} &= \int_{\mathcal{R}(X)}\mathopen{}\left(\int_{\mathcal{R}(Y)} h(x, y)\,f_{X,Y}(x, y)\,d\mu_Y(y)\right)\mathclose{}\,d\mu_X(x) \\&= \int_{\mathcal{R}(Y)}\mathopen{}\left(\int_{\mathcal{R}(X)} h(x, y)\,f_{X,Y}(x, y)\,d\mu_X(x)\right)\mathclose{}\,d\mu_Y(y). \end{aligned} \]

The choice of reference measures covers three cases:

  • Both continuous:

    \[ \begin{aligned} \mu_X &= \mu_Y \\ &= \text{Lebesgue measure}; \end{aligned} \]

    \(f_{X,Y}\) is the joint probability density function (PDF), and \(\int_{\mathcal{R}(X)} g(x)\,d\mu_X(x) = \int_{\mathcal{R}(X)} g(x)\,dx\).

  • Both discrete:

    \[ \begin{aligned} \mu_X &= \mu_Y \\ &= \text{counting measure}; \end{aligned} \]

    \(f_{X,Y}(x,y) = \mathbb{P}(X = x,\, Y = y)\) is the joint probability mass function (PMF), and \(\int_{\mathcal{R}(X)} g(x)\,d\mu_X(x) = \sum_{x \in \mathcal{R}(X)} g(x)\).

  • Mixed (one continuous, one discrete): one reference measure is Lebesgue and the other is counting; \(f_{X,Y}\) is the joint density-mass function, \(f_{X,Y}(x,y) = f_{X \mid Y}(x \mid y)\,\mathbb{P}(Y = y)\) (or \(\mathbb{P}(X = x \mid Y = y)\,f_Y(y)\) if \(X\) is discrete and \(Y\) continuous), and the iterated integrals combine an ordinary integral with a sum. The conditional densities/PMFs here are defined the same way as in Definition 6, just conditioning on \(Y\) instead of \(X\).

ProofProof

Proof. Apply Theorem 9 with \(\mu_1 = \mu_X\) and \(\mu_2 = \mu_Y\) to the integrand \(h(x,y)\,f_{X,Y}(x,y)\) on \(\mathcal{R}(X) \times \mathcal{R}(Y)\). Lebesgue measure and counting measure on a countable set are each \(\sigma\)-finite, so \(\mu_X \otimes \mu_Y\) is \(\sigma\)-finite in all three cases. The relevant condition is (a) when \(h \ge 0\) and (b) when \({\mathbb{E}\mathopen{}\left[\mathopen{}\left|h(X, Y)\right|\mathclose{}\right]\mathclose{}} < \infty\). Independence is not required. When \(X\) and \(Y\) are independent, \(f_{X,Y}(x,y) = f_X(x)\,f_Y(y)\) (or \(\mathbb{P}(X=x,Y=y) = \mathbb{P}(X=x)\,\mathbb{P}(Y=y)\) in the discrete case), and the iterated integrals factor into separate integrals over the marginals.

ExmExample 18 (Expectation of a product of independent variables)

Example 18 (Expectation of a product of independent variables) Let \(X \sim \mathrm{Uniform}(0, 1)\) and \(Y \sim \mathrm{Uniform}(0, 2)\), independently distributed. Compute \({\mathbb{E}\mathopen{}\left[XY\right]\mathclose{}}\).

We apply Corollary 3 (both-continuous case) with \(h(x, y) = xy\). Since \(X\) and \(Y\) are independent with densities \(f_X(x) = 1\) on \([0,1]\) and \(f_Y(y) = \tfrac{1}{2}\) on \([0,2]\), the joint density factors as

\[ \begin{aligned} f_{X,Y}(x,y) &= f_X(x)\,f_Y(y) \\ &= \tfrac{1}{2}, \end{aligned} \]

and

\[ \begin{aligned} \mu_X &= \mu_Y \\ &= \text{Lebesgue measure}: \end{aligned} \]

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[XY\right]\mathclose{}} &= \int_0^1 \mathopen{}\left(\int_0^2 xy \cdot\tfrac{1}{2}\,dy\right)\mathclose{}\,dx && \text{(joint-distribution form of Fubini--Tonelli)} \\&= \int_0^1 x\mathopen{}\left(\frac{1}{2}\int_0^2 y\,dy\right)\mathclose{}\,dx && \text{(factor constants out of the inner integral)} \\&= \int_0^1 x \cdot\frac{1}{2} \cdot\mathopen{}\left[\frac{y^2}{2}\right]\mathclose{}_0^2\,dx && \text{(antiderivative of } y \text{)} \\&= \int_0^1 x \cdot\frac{1}{2} \cdot 2\,dx && \text{(evaluate at the bounds)} \\&= \int_0^1 x\,dx && \text{(simplify)} \\&= \frac{1}{2} && \text{(integrate)} \end{aligned} \]

As a check: \({\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} = \tfrac{1}{2}\), \({\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} = 1\), and \({\mathbb{E}\mathopen{}\left[X\right]\mathclose{}}{\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} = \tfrac{1}{2}\).

ExmExample 19 (When independence fails: a counterexample)

Example 19 (When independence fails: a counterexample) Correctly applying Corollary 3 requires the actual joint density \(f_{X,Y}\) — not the product of marginals \(f_X(x)\,f_Y(y)\), which is valid only when \(X\) and \(Y\) are independent. Using the wrong joint density gives the wrong answer.

Let \(X \sim \mathrm{Uniform}(0, 1)\) and set \(Y = X\) (so \(X\) and \(Y\) are perfectly correlated and not independent).

True expectation:

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[XY\right]\mathclose{}} &= {\mathbb{E}\mathopen{}\left[X \cdot X\right]\mathclose{}} && \text{(} Y = X \text{)} \\&= {\mathbb{E}\mathopen{}\left[X^2\right]\mathclose{}} && \text{(} X \cdot X = X^2 \text{)} \\&= \int_0^1 x^2\,dx && \text{(LOTUS, with the uniform density } 1 \text{ on } [0, 1] \text{)} \\&= \frac{1}{3} && \text{(integrate)} \end{aligned} \]

Erroneously applying the product-measure formula:

Note that Fubini–Tonelli’s own conditions still hold here (\(h(x,y) = xy\) is nonnegative and integrable), so the error is not a failure of Fubini–Tonelli itself. Rather, the error is using the wrong measure: the joint distribution of \((X, X)\) is concentrated on the diagonal \(\{(x, x) : x \in [0, 1]\} \subset [0, 1]^2\), which has Lebesgue measure zero in \(\mathbb{R}^2\). The joint distribution is therefore not absolutely continuous with respect to two-dimensional Lebesgue measure, so no joint density \(f_{X,Y}\) on \([0, 1]^2\) exists, which is the reference density Corollary 3 requires.

The following calculation is what someone would erroneously write if they assumed independence and used \(f_X(x)\,f_Y(y)\) as a “joint density” — a function that does not in fact correspond to the joint distribution of \((X, X)\). The marginals \(X \sim \mathrm{Uniform}(0,1)\) and \(Y \sim \mathrm{Uniform}(0,1)\) do have densities

\[ \begin{aligned} f_X &= f_Y \\ &= 1, \end{aligned} \]

but the product \(f_X(x)\,f_Y(y) = 1\) on \([0, 1]^2\) is the density of an independent pair, not of \((X, X)\):

\[ \begin{aligned} \int_0^1\!\int_0^1 xy \cdot f_X(x) \cdot f_Y(y)\,dy\,dx &= \int_0^1\!\int_0^1 xy\,dy\,dx && \text{(} f_X(x)\,f_Y(y) = 1 \text{ on } [0, 1]^2 \text{)} \\&= \int_0^1 x\mathopen{}\left(\int_0^1 y\,dy\right)\mathclose{}\,dx && \text{(factor } x \text{ out of the inner integral)} \\&= \int_0^1 x \cdot\frac{1}{2}\,dx && \text{(} \textstyle\int_0^1 y\,dy = \tfrac{1}{2} \text{)} \\&= \frac{1}{4} && \text{(} \textstyle\int_0^1 \tfrac{x}{2}\,dx = \tfrac{1}{4} \text{)} \end{aligned} \]

This calculation recovers \({\mathbb{E}\mathopen{}\left[XY\right]\mathclose{}}\) for independent uniforms (\(\tfrac{1}{4}\)), not \({\mathbb{E}\mathopen{}\left[XX\right]\mathclose{}}\) for the perfectly correlated pair (\(\tfrac{1}{3}\)). The lesson is that Corollary 3 requires the actual joint density \(f_{X,Y}\). For independent \((X, Y)\), this density factors as \(f_X(x)\,f_Y(y)\); for dependent \((X, Y)\), \(f_{X,Y}\) need not factor — and for \((X, X)\), no joint density on \(\mathbb{R}^2\) exists at all, so Corollary 3 simply does not apply.

LemTheorem 10 (Law of iterated expectations)

Theorem 10 (Law of iterated expectations) For any two random variables \(X\) and \(Y\) with \({\mathbb{E}\mathopen{}\left[\mathopen{}\left|Y\right|\mathclose{}\right]\mathclose{}} < \infty\):

\[{\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} = {\mathbb{E}\mathopen{}\left[{\mathbb{E}\mathopen{}\left[Y \mid X\right]\mathclose{}}\right]\mathclose{}}\]

ProofProof

Proof. Discrete case. When \(X\) and \(Y\) are discrete, applying Definition 1 to \({\mathbb{E}\mathopen{}\left[{\mathbb{E}\mathopen{}\left[Y \mid X\right]\mathclose{}}\right]\mathclose{}}\) and then the law of total probability applied to the countable partition \(\{X = x : x \in \mathcal{R}(X)\}\):

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[{\mathbb{E}\mathopen{}\left[Y \mid X\right]\mathclose{}}\right]\mathclose{}} &= \sum_{x \in \mathcal{R}(X)} {\mathbb{E}\mathopen{}\left[Y \mid X=x\right]\mathclose{}} \cdot\mathbb{P}(X=x) && \text{(LOTUS for the function } x \mapsto {\mathbb{E}\mathopen{}\left[Y \mid X=x\right]\mathclose{}} \text{)} \\&= \sum_{x \in \mathcal{R}(X)} \mathopen{}\left(\sum_{y \in \mathcal{R}(Y)} y \cdot\mathbb{P}(Y=y \mid X=x)\right)\mathclose{} \cdot\mathbb{P}(X=x) && \text{(definition of conditional expectation } {\mathbb{E}\mathopen{}\left[Y \mid X=x\right]\mathclose{}} \text{)} \\&= \sum_{y \in \mathcal{R}(Y)} y \cdot\sum_{x \in \mathcal{R}(X)} \mathbb{P}(Y=y \mid X=x) \cdot\mathbb{P}(X=x) && \text{(exchange order of summation: Fubini, since } {\mathbb{E}\mathopen{}\left[\mathopen{}\left|Y\right|\mathclose{}\right]\mathclose{}} < \infty \text{)} \\&= \sum_{y \in \mathcal{R}(Y)} y \cdot\mathbb{P}(Y=y) && \text{(law of total probability over } X \text{)} \\&= {\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} && \text{(definition of expectation of } Y \text{)} \end{aligned} \]

Continuous case. When \(X\) and \(Y\) are continuous:

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[{\mathbb{E}\mathopen{}\left[Y \mid X\right]\mathclose{}}\right]\mathclose{}} &= \int_{x \in \mathcal{R}(X)} {\mathbb{E}\mathopen{}\left[Y \mid X=x\right]\mathclose{}} \cdot\operatorname{p}(X=x)\, dx && \text{(LOTUS)} \\&= \int_{x \in \mathcal{R}(X)} \mathopen{}\left(\int_{y \in \mathcal{R}(Y)} y \cdot\operatorname{p}(Y=y \mid X=x)\, dy\right)\mathclose{} \cdot\operatorname{p}(X=x)\, dx && \text{(definition of conditional expectation)} \\&= \int_{x \in \mathcal{R}(X)} \int_{y \in \mathcal{R}(Y)} y \cdot\operatorname{p}(X=x, Y=y)\, dy\, dx && \text{(definition of conditional density: } \operatorname{p}(Y=y \mid X=x)\,\operatorname{p}(X=x) = \operatorname{p}(X=x, Y=y) \text{)} \\&= \int_{y \in \mathcal{R}(Y)} y \cdot\mathopen{}\left(\int_{x \in \mathcal{R}(X)} \operatorname{p}(X=x, Y=y)\, dx\right)\mathclose{}\, dy && \text{(Fubini's theorem, since } {\mathbb{E}\mathopen{}\left[\mathopen{}\left|Y\right|\mathclose{}\right]\mathclose{}} < \infty \text{)} \\&= \int_{y \in \mathcal{R}(Y)} y \cdot\operatorname{p}(Y=y)\, dy && \text{(marginal density from a joint density)} \\&= {\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} && \text{(definition of expectation)} \end{aligned} \]

Mixed case, \(X\) discrete and \(Y\) continuous. With the joint density-mass function \(\operatorname{p}(X = x,\, Y = y)\), Corollary 3 applies with \(h(x, y) = y\), counting measure for \(X\), and Lebesgue measure for \(Y\); its condition (b) holds because \({\mathbb{E}\mathopen{}\left[\mathopen{}\left|Y\right|\mathclose{}\right]\mathclose{}} < \infty\). The sum runs over the \(x\) with \(\mathbb{P}(X = x) > 0\), where Definition 6 defines \({\mathbb{E}\mathopen{}\left[Y \mid X = x\right]\mathclose{}}\):

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[{\mathbb{E}\mathopen{}\left[Y \mid X\right]\mathclose{}}\right]\mathclose{}} &= \sum_{x \in \mathcal{R}(X)} {\mathbb{E}\mathopen{}\left[Y \mid X=x\right]\mathclose{}} \cdot\mathbb{P}(X=x) && \text{(LOTUS, discrete case)} \\&= \sum_{x \in \mathcal{R}(X)} \mathopen{}\left(\int_{\mathcal{R}(Y)} y \cdot\operatorname{p}(Y=y \mid X=x)\,dy\right)\mathclose{} \cdot\mathbb{P}(X=x) && \text{(definition of conditional expectation, mixed case)} \\&= \sum_{x \in \mathcal{R}(X)} \int_{\mathcal{R}(Y)} y \cdot\operatorname{p}(Y=y \mid X=x) \cdot\mathbb{P}(X=x)\,dy && \text{(move the constant } \mathbb{P}(X=x) \text{ inside the integral)} \\&= \sum_{x \in \mathcal{R}(X)} \int_{\mathcal{R}(Y)} y \cdot\operatorname{p}(X=x,\, Y=y)\,dy && \text{(definition of the conditional density, mixed case)} \\&= {\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} && \text{(joint-distribution form of Fubini--Tonelli, with } h(x, y) = y \text{)} \end{aligned} \]

Mixed case, \(X\) continuous and \(Y\) discrete. The same steps apply with the integral and the sum swapped, over the \(x\) with \(\operatorname{p}(X = x) > 0\); at any other \(x\), \(\operatorname{p}(X = x,\, Y = y) = 0\) for every \(y\), because these non-negative terms sum to \(\operatorname{p}(X = x)\):

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[{\mathbb{E}\mathopen{}\left[Y \mid X\right]\mathclose{}}\right]\mathclose{}} &= \int_{\mathcal{R}(X)} {\mathbb{E}\mathopen{}\left[Y \mid X=x\right]\mathclose{}} \cdot\operatorname{p}(X=x)\,dx && \text{(LOTUS, continuous case)} \\&= \int_{\mathcal{R}(X)} \mathopen{}\left(\sum_{y \in \mathcal{R}(Y)} y \cdot\mathbb{P}(Y=y \mid X=x)\right)\mathclose{} \cdot\operatorname{p}(X=x)\,dx && \text{(definition of conditional expectation, mixed case)} \\&= \int_{\mathcal{R}(X)} \sum_{y \in \mathcal{R}(Y)} y \cdot\mathbb{P}(Y=y \mid X=x) \cdot\operatorname{p}(X=x)\,dx && \text{(move the constant } \operatorname{p}(X=x) \text{ inside the sum)} \\&= \int_{\mathcal{R}(X)} \sum_{y \in \mathcal{R}(Y)} y \cdot\operatorname{p}(X=x,\, Y=y)\,dx && \text{(definition of the conditional PMF, mixed case)} \\&= {\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} && \text{(joint-distribution form of Fubini--Tonelli, with } h(x, y) = y \text{)} \end{aligned} \]

RemarkRemark

Remark. Alternate names for this identity include: the tower rule, the tower property, the law of total expectation, and the smoothing theorem.

LemTheorem 11 (Conditional law of iterated expectations)

Theorem 11 (Conditional law of iterated expectations) For random variables \(X\), \(Y\), and \(Z\) with \({\mathbb{E}\mathopen{}\left[\mathopen{}\left|Y\right|\mathclose{}\right]\mathclose{}} < \infty\):

\[{\mathbb{E}\mathopen{}\left[Y \mid Z\right]\mathclose{}} = {\mathbb{E}\mathopen{}\left[{\mathbb{E}\mathopen{}\left[Y \mid X,Z\right]\mathclose{}} \mid Z\right]\mathclose{}}\]

ProofProof

Proof. Choose a value \(z\) with positive probability (discrete case) or positive density (continuous case). Conditioning every probability on \(Z = z\) gives a probability measure, and the proof of Theorem 10 goes through under it, line by line.

Discrete case.

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[{\mathbb{E}\mathopen{}\left[Y \mid X,Z\right]\mathclose{}} \mid Z=z\right]\mathclose{}} &= \sum_{x \in \mathcal{R}(X)} {\mathbb{E}\mathopen{}\left[Y \mid X=x,Z=z\right]\mathclose{}} \cdot\mathbb{P}(X=x \mid Z=z) && \text{(expectation given } Z=z \text{)} \\&= \sum_{x \in \mathcal{R}(X)} \mathopen{}\left(\sum_{y \in \mathcal{R}(Y)} y \cdot\mathbb{P}(Y=y \mid X=x,Z=z)\right)\mathclose{} \cdot\mathbb{P}(X=x \mid Z=z) && \text{(definition of } {\mathbb{E}\mathopen{}\left[Y \mid X=x,Z=z\right]\mathclose{}} \text{)} \\&= \sum_{y \in \mathcal{R}(Y)} y \cdot\sum_{x \in \mathcal{R}(X)} \mathbb{P}(Y=y \mid X=x,Z=z) \cdot\mathbb{P}(X=x \mid Z=z) && \text{(exchange order of summation)} \\&= \sum_{y \in \mathcal{R}(Y)} y \cdot\mathbb{P}(Y=y \mid Z=z) && \text{(law of total probability given } Z=z \text{)} \\&= {\mathbb{E}\mathopen{}\left[Y \mid Z=z\right]\mathclose{}} && \text{(definition of conditional expectation given } Z=z \text{)} \end{aligned} \]

Continuous case.

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[{\mathbb{E}\mathopen{}\left[Y \mid X,Z\right]\mathclose{}} \mid Z=z\right]\mathclose{}} &= \int_{x \in \mathcal{R}(X)} {\mathbb{E}\mathopen{}\left[Y \mid X=x,Z=z\right]\mathclose{}} \cdot\operatorname{p}(X=x \mid Z=z)\, dx && \text{(expectation given } Z=z \text{)} \\&= \int_{x \in \mathcal{R}(X)} \mathopen{}\left(\int_{y \in \mathcal{R}(Y)} y \cdot\operatorname{p}(Y=y \mid X=x,Z=z)\, dy\right)\mathclose{} \cdot\operatorname{p}(X=x \mid Z=z)\, dx && \text{(definition of } {\mathbb{E}\mathopen{}\left[Y \mid X=x,Z=z\right]\mathclose{}} \text{)} \\&= \int_{x \in \mathcal{R}(X)} \int_{y \in \mathcal{R}(Y)} y \cdot\operatorname{p}(X=x, Y=y \mid Z=z)\, dy\, dx && \text{(product of conditional densities is the joint conditional density)} \\&= \int_{y \in \mathcal{R}(Y)} y \cdot\mathopen{}\left(\int_{x \in \mathcal{R}(X)} \operatorname{p}(X=x, Y=y \mid Z=z)\, dx\right)\mathclose{}\, dy && \text{(Fubini's theorem)} \\&= \int_{y \in \mathcal{R}(Y)} y \cdot\operatorname{p}(Y=y \mid Z=z)\, dy && \text{(marginalize over } x \text{)} \\&= {\mathbb{E}\mathopen{}\left[Y \mid Z=z\right]\mathclose{}} && \text{(definition of conditional expectation given } Z=z \text{)} \end{aligned} \]

Since the two sides agree at every such \(z\), they agree as random variables (functions of \(Z\)): \({\mathbb{E}\mathopen{}\left[Y \mid Z\right]\mathclose{}} = {\mathbb{E}\mathopen{}\left[{\mathbb{E}\mathopen{}\left[Y \mid X,Z\right]\mathclose{}} \mid Z\right]\mathclose{}}\).

Remark. This identity is the tower rule applied conditionally on \(Z\).

ExrExercise 3 (Both-discrete case, infinite support: joint PMF)

Exercise 3 (Both-discrete case, infinite support: joint PMF) Let \(X\) and \(Y\) be independent, each Geometric on

\[ \begin{aligned} \mathcal{R}(X) &= \mathcal{R}(Y) \\ &= \{0, 1, 2, \dots\} \end{aligned} \]

with \(\mathbb{P}(X = x) = (1-p)\,p^x\) for a fixed \(p \in (0, 1)\) (\(X\) counts the number of failures before the first success in a sequence of independent trials with success probability \(1-p\); likewise for \(Y\)). Unlike Exercise 2, the support here is countably infinite. The joint PMF is \(\mathbb{P}(X = x,\, Y = y) = (1-p)^2\,p^{x+y}\).

Compute \({\mathbb{E}\mathopen{}\left[X + Y\right]\mathclose{}}\).

SolutionSolution

Solution. Compute \({\mathbb{E}\mathopen{}\left[X + Y\right]\mathclose{}}\) using Corollary 3 with

\[ \begin{aligned} \mu_X &= \mu_Y \\ &= \text{counting measure} \end{aligned} \]

and \(h(x, y) = x + y\). Since \(h(x,y) = x + y \ge 0\) for every \((x,y)\) in this support, condition (a) holds, so Corollary 3 (via Tonelli’s theorem) guarantees the order of this now-infinite double sum is exchangeable — unlike the finite case, elementary algebra alone could not establish this.

The derivation uses the standard geometric-series facts \(\sum_{y=0}^{\infty} p^y = \frac{1}{1-p}\) and \(\sum_{y=0}^{\infty} y\,p^y = \frac{p}{(1-p)^2}\) (e.g. Casella and Berger [6]). By Corollary 3 (both-discrete case), summing over \(y\) first for each fixed \(x\):

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[X + Y\right]\mathclose{}} &= \sum_{x=0}^{\infty} \sum_{y=0}^{\infty} (x + y)\,\mathbb{P}(X = x,\, Y = y) && \text{(joint-distribution form of Fubini--Tonelli)} \\&= \sum_{x=0}^{\infty} \sum_{y=0}^{\infty} (x + y)(1-p)^2 p^{x+y} && \text{(substitute the joint PMF)} \\&= \sum_{x=0}^{\infty} (1-p)^2 p^x \sum_{y=0}^{\infty} (x + y)\,p^y && \text{(factor } (1-p)^2 p^x \text{ out of the inner sum)} \\&= \sum_{x=0}^{\infty} (1-p)^2 p^x \mathopen{}\left(x \sum_{y=0}^{\infty} p^y + \sum_{y=0}^{\infty} y\,p^y\right)\mathclose{} && \text{(split the inner sum; factor out } x \text{)} \\&= \sum_{x=0}^{\infty} (1-p)^2 p^x \mathopen{}\left(\frac{x}{1-p} + \frac{p}{(1-p)^2}\right)\mathclose{} && \text{(geometric-series facts)} \\&= \sum_{x=0}^{\infty} p^x \mathopen{}\left[x(1-p) + p\right]\mathclose{} && \text{(multiply } (1-p)^2 \text{ into the parentheses)} \\&= (1-p) \sum_{x=0}^{\infty} x\,p^x + p \sum_{x=0}^{\infty} p^x && \text{(distribute the sum over the terms; factor out the constants)} \\&= (1-p) \cdot\frac{p}{(1-p)^2} + p \cdot\frac{1}{1-p} && \text{(geometric-series facts)} \\&= \frac{p}{1-p} + \frac{p}{1-p} && \text{(cancel } 1 - p \text{)} \\&= \frac{2p}{1-p} && \text{(add)} \end{aligned} \]

As a check,

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} &= {\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} \\ &= \frac{p}{1-p} \end{aligned} \]

(the mean of this Geometric distribution; Casella and Berger [6]), so

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[X + Y\right]\mathclose{}} &= {\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} + {\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} \\ &= \frac{2p}{1-p} \end{aligned} \]

by linearity of expectation, matching.

NoteTonelli’s nonnegativity condition, and what happens without it

The calculation in Exercise 3 only needed condition (a), \(h(X,Y) \ge 0\), because \(h(x,y) = x+y\) is nonnegative on this support. For a signed \(h\), interchanging an infinite double sum is not automatically valid — Corollary 3’s condition (b), \({\mathbb{E}\mathopen{}\left[\mathopen{}\left|h(X,Y)\right|\mathclose{}\right]\mathclose{}} < \infty\), is what licenses it in that case. Without either condition, the two orders can genuinely disagree. A standard example (a signed array, not a probability distribution; see e.g. [11], Theorem 3.54, p. 76 for the general theory of rearranging series): let \(a_{m,n} = 1\) if \(m = n\), \(a_{m,n} = -1\) if \(m = n+1\), and \(a_{m,n} = 0\) otherwise, for \(m, n = 0, 1, 2, \dots\). Summing each row \(m\) first: row \(0\) has only the term \(a_{0,0}=1\) (there is no valid \(n = -1\)), so its row sum is \(1\); every row \(m \ge 1\) has \(a_{m,m} = 1\) and \(a_{m,m-1} = -1\), so its row sum is \(0\). Summing the rows then gives \(1 + 0 + 0 + \cdots = 1\). Summing each column \(n\) first: every column \(n \ge 0\) has \(a_{n,n} = 1\) and \(a_{n+1,n} = -1\), so its column sum is always \(0\), and summing the columns then gives \(0 + 0 + \cdots = 0\). The two orders give \(1\) and \(0\): genuinely different answers, confirming that a condition like (a) or (b) really is needed once the terms are no longer all nonnegative.

ExrExercise 4 (Mixed case: one continuous variable, one discrete variable)

Exercise 4 (Mixed case: one continuous variable, one discrete variable) Let \(Y \sim \mathrm{Bernoulli}(0.6)\) and, given \(Y = y\), let \(X \mid Y = y \sim \mathrm{Uniform}(0,\, y + 1)\).

Compute \({\mathbb{E}\mathopen{}\left[X\right]\mathclose{}}\).

SolutionSolution

Solution. Compute \({\mathbb{E}\mathopen{}\left[X\right]\mathclose{}}\) using Corollary 3 with \(\mu_X = \text{Lebesgue measure}\), \(\mu_Y = \text{counting measure}\), and \(h(x, y) = x\).

The joint density w.r.t. Lebesgue \(\times\) counting measure is \(f_{X,Y}(x, y) = f_{X \mid Y}(x \mid y)\,\mathbb{P}(Y = y)\):

\[ \begin{aligned} f_{X,Y}(x,\, 0) &= 1 \cdot 0.4 \\ &= 0.4 &&\text{ for } x \in [0,1]; \\ f_{X,Y}(x,\, 1) &= \tfrac{1}{2} \cdot 0.6 \\ &= 0.3 &&\text{ for } x \in [0,2]. \end{aligned} \]

By Corollary 3 (mixed case):

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} &= \sum_{y \in \{0,1\}} \int_0^{y+1} x\,f_{X,Y}(x,\, y)\,dx && \text{(joint-distribution form of Fubini--Tonelli, mixed case)} \\ &= \int_0^1 x \cdot 0.4\,dx + \int_0^2 x \cdot 0.3\,dx && \text{(expand the sum over } y \in \{0, 1\} \text{; substitute } f_{X,Y} \text{)} \\ &= 0.4 \cdot \frac{1}{2} + 0.3 \cdot 2 && \text{(} \textstyle\int_0^b x\,dx = b^2/2 \text{)} \\ &= 0.2 + 0.6 && \text{(multiply)} \\ &= 0.8 && \text{(add)} \end{aligned} \]

As a check using the law of iterated expectations (Theorem 10): \({\mathbb{E}\mathopen{}\left[X \mid Y = 0\right]\mathclose{}} = \tfrac{1}{2}\) and \({\mathbb{E}\mathopen{}\left[X \mid Y = 1\right]\mathclose{}} = 1\), so

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} &= \tfrac{1}{2}(0.4) + 1(0.6) \\ &= 0.2 + 0.6 \\ &= 0.8. \end{aligned} \]

ExrExercise 5 (Mixed case, infinite discrete support)

Exercise 5 (Mixed case, infinite discrete support) Let \(Y\) be Geometric on \(\{0, 1, 2, \dots\}\) with \(\mathbb{P}(Y = y) = (1-q)\,q^y\) for a fixed \(q \in (0, 1)\) and, given \(Y = y\), let \(X \mid Y = y \sim \mathrm{Uniform}(0,\, y+1)\). Unlike Exercise 4, \(Y\)’s range here is countably infinite.

Compute \({\mathbb{E}\mathopen{}\left[X\right]\mathclose{}}\).

SolutionSolution

Solution. Compute \({\mathbb{E}\mathopen{}\left[X\right]\mathclose{}}\) using Corollary 3 with \(\mu_X = \text{Lebesgue measure}\), \(\mu_Y = \text{counting measure}\), and \(h(x, y) = x\).

The joint density w.r.t. Lebesgue \(\times\) counting measure is

\[ \begin{aligned} f_{X,Y}(x, y) &= f_{X \mid Y}(x \mid y)\,\mathbb{P}(Y = y) \\ &= \frac{(1-q)\,q^y}{y+1} \end{aligned} \]

for \(x \in [0, y+1]\).

Since \(h(x, y) = x \ge 0\) on this support, condition (a) holds, so Corollary 3 (via Tonelli’s theorem) guarantees the now-infinite sum-of-integrals expression is valid — unlike in Exercise 4, this Fubini–Tonelli justification is required because the sum is infinite rather than finite.

By Corollary 3 (mixed case):

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} &= \sum_{y=0}^{\infty} \int_0^{y+1} x\,f_{X,Y}(x,\,y)\,dx && \text{(joint-distribution form of Fubini--Tonelli, mixed case)} \\&= \sum_{y=0}^{\infty} \frac{(1-q)\,q^y}{y+1} \int_0^{y+1} x\,dx && \text{(} f_{X,Y}(x, y) \text{ is constant in } x \text{ on } [0, y+1] \text{)} \\&= \sum_{y=0}^{\infty} \frac{(1-q)\,q^y}{y+1} \cdot\frac{(y+1)^2}{2} && \text{(integrate)} \\&= \frac{1-q}{2} \sum_{y=0}^{\infty} (y+1)\,q^y && \text{(cancel } y + 1 \text{; factor out } \tfrac{1-q}{2} \text{)} \\&= \frac{1-q}{2} \mathopen{}\left(\sum_{y=0}^{\infty} y\,q^y + \sum_{y=0}^{\infty} q^y\right)\mathclose{} && \text{(distribute the sum over the terms)} \\&= \frac{1-q}{2} \mathopen{}\left(\frac{q}{(1-q)^2} + \frac{1}{1-q}\right)\mathclose{} && \text{(geometric-series facts)} \\&= \frac{1-q}{2} \cdot\frac{q + (1-q)}{(1-q)^2} && \text{(common denominator)} \\&= \frac{1-q}{2} \cdot\frac{1}{(1-q)^2} && \text{(simplify the numerator)} \\&= \frac{1}{2(1-q)} && \text{(cancel } 1 - q \text{)} \end{aligned} \]

using the same geometric-series facts as Exercise 3 (e.g. Casella and Berger [6]).

As a check using the law of iterated expectations (Theorem 10) and the expectation of a linear function (Corollary 1): \({\mathbb{E}\mathopen{}\left[X \mid Y=y\right]\mathclose{}} = \frac{y+1}{2}\) (the mean of \(\mathrm{Uniform}(0,y+1)\)) and \({\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} = \frac{q}{1-q}\) (the mean of this Geometric distribution; Casella and Berger [6]), so:

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[X\right]\mathclose{}} &= {\mathbb{E}\mathopen{}\left[{\mathbb{E}\mathopen{}\left[X \mid Y\right]\mathclose{}}\right]\mathclose{}} && \text{(law of iterated expectations)} \\&= {\mathbb{E}\mathopen{}\left[\frac{Y+1}{2}\right]\mathclose{}} && \text{(} {\mathbb{E}\mathopen{}\left[X \mid Y = y\right]\mathclose{}} = \tfrac{y+1}{2} \text{)} \\&= \frac{{\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} + 1}{2} && \text{(expectation of a linear function of one random variable)} \\&= \frac{1}{2}\mathopen{}\left(\frac{q}{1-q} + 1\right)\mathclose{} && \text{(substitute } {\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} \text{)} \\&= \frac{1}{2} \cdot\frac{q + (1-q)}{1-q} && \text{(common denominator)} \\&= \frac{1}{2(1-q)} && \text{(simplify the numerator)} \end{aligned} \]

matching.

0.3 Loss and risk

DefDefinition 9 (Prediction)

Definition 9 (Prediction) A prediction of a random variable \(Y\) is a constant \(\hat y\), or a function \(\hat{Y} \stackrel{\text{def}}{=}g(X)\) of another observable random variable \(X\), used as a guess for the value \(Y\) takes:

\[\hat y\quad \text{or} \quad \hat{Y} \stackrel{\text{def}}{=}g(X)\]

ExmExample 23 (Predictions of a die roll)

Example 23 (Predictions of a die roll) Let \(Y\) be the number shown by a fair six-sided die. The constant \(\hat y= 3\) is a prediction of \(Y\).

Let \(X\) be the indicator that \(Y\) is even. The function \(g(X) = 2 + 2X\) is also a prediction of \(Y\): it guesses \(2\) when \(Y\) is odd and \(4\) when \(Y\) is even.

RemarkRemark 2 (A prediction from a random input is random)

Remark 2 (A prediction from a random input is random). When no covariate or feature is available, a prediction is a single number \(\hat y\) (such as a constant \(c\)). When an informative random variable \(X\) is observed, a prediction is a function \(g(X)\), which is itself a random variable because \(X\) is random.

DefDefinition 10 (Loss function)

Definition 10 (Loss function) A loss function \(L(y, \hat y)\) is a rule that gives a number that is 0 or larger: the cost of predicting \(\hat y\) when the true value is \(y\) [12].

ExmExample 24 (A loss function that charges more for overpredicting)

Example 24 (A loss function that charges more for overpredicting) Let \(L(y, \hat y)\) cost \(2\) per unit of overprediction and \(1\) per unit of underprediction:

\[ L(y, \hat y) = \begin{cases} 2\mathopen{}\left(\hat y- y\right)\mathclose{} & \text{if } \hat y> y \\ y - \hat y& \text{if } \hat y\le y. \end{cases} \]

This is a loss function because it is never negative. For the true value \(y = 2\) and the prediction \(\hat y= 7\), the loss is \(L(2, 7) = 2 \cdot 5 = 10\). For \(y = 7\) and \(\hat y= 2\), the loss is \(L(7, 2) = 5\).

DefDefinition 11 (Squared error loss)

Definition 11 (Squared error loss) The squared error loss is the loss function that charges the square of the difference between the true value \(y\) and the prediction \(\hat y\):

\[L(y, \hat y) \stackrel{\text{def}}{=}{\mathopen{}\left(y - \hat y\right)\mathclose{}}^{2}\]

ExmExample 25 (Squared error loss for one prediction)

Example 25 (Squared error loss for one prediction) For the true value \(y = 2\) and the prediction \(\hat y= 7\), the squared error loss is

\[{\mathopen{}\left(2 - 7\right)\mathclose{}}^{2} = 25.\]

DefDefinition 12 (Absolute error loss)

Definition 12 (Absolute error loss) The absolute error loss is the loss function that charges the absolute value of the difference between the true value \(y\) and the prediction \(\hat y\):

\[L(y, \hat y) \stackrel{\text{def}}{=}\mathopen{}\left|y - \hat y\right|\mathclose{}\]

ExmExample 26 (Absolute error loss for one prediction)

Example 26 (Absolute error loss for one prediction) For the true value \(y = 2\) and the prediction \(\hat y= 7\), the absolute error loss is

\[\mathopen{}\left|2 - 7\right|\mathclose{} = 5.\]

RemarkRemark 3 (Squared error loss is the most common choice)

Remark 3 (Squared error loss is the most common choice). Hastie et al. [13, p. 18] call squared error loss “by far the most common and convenient” choice.

DefDefinition 13 (Risk (expected loss))

Definition 13 (Risk (expected loss)) For a random variable \(Y\) and a prediction \(\hat y\) (a constant, or a function \(g(X)\) of a random input \(X\)), the risk is the expectation of the loss [14]:

\[R \stackrel{\text{def}}{=}{\mathbb{E}\mathopen{}\left[L(Y, \hat y)\right]\mathclose{}}\]

ExmExample 27 (Risk of a constant prediction)

Example 27 (Risk of a constant prediction) Let \(Y\) be a random variable with \(\mathbb{P}(Y = 0) = 0.5\) and \(\mathbb{P}(Y = 2) = 0.5\), and use the constant prediction \(\hat y= 0\). The risk under squared error loss is

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[{\mathopen{}\left(Y - 0\right)\mathclose{}}^{2}\right]\mathclose{}} &= 0.5 \cdot{\mathopen{}\left(0 - 0\right)\mathclose{}}^{2} + 0.5 \cdot{\mathopen{}\left(2 - 0\right)\mathclose{}}^{2} \\ &= 2. \end{aligned} \]

The risk under absolute error loss is

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[\mathopen{}\left|Y - 0\right|\mathclose{}\right]\mathclose{}} &= 0.5 \cdot\mathopen{}\left|0 - 0\right|\mathclose{} + 0.5 \cdot\mathopen{}\left|2 - 0\right|\mathclose{} \\ &= 1. \end{aligned} \]

RemarkRemark 4 (Risk measures the quality of a prediction)

Remark 4 (Risk measures the quality of a prediction). The quality of a prediction is evaluated using a loss function and its expected value, the risk.

ExrExercise 6 (Squared and absolute loss)

Exercise 6 (Squared and absolute loss)  

  1. For a true value \(y = 3\) and a prediction \(\hat y= 5\), compute the squared error loss \({\mathopen{}\left(y - \hat y\right)\mathclose{}}^{2}\) and the absolute error loss \(\mathopen{}\left|y - \hat y\right|\mathclose{}\).

  2. A random variable \(Y\) has \(\mathbb{P}(Y = 0) = 0.5\) and \(\mathbb{P}(Y = 4) = 0.5\). For the constant prediction \(c = 1\), compute the risk under squared error loss \({\mathbb{E}\mathopen{}\left[{\mathopen{}\left(Y - c\right)\mathclose{}}^{2}\right]\mathclose{}}\) and the risk under absolute error loss \({\mathbb{E}\mathopen{}\left[\mathopen{}\left|Y - c\right|\mathclose{}\right]\mathclose{}}\).

  3. Repeat part 2 for \(c = 2\).

  4. Which of \(c = 1\) and \(c = 2\) gives the smaller risk under each loss?

SolutionSolution 2

Solution 2.

  1. For squared error loss: \[{\mathopen{}\left(3 - 5\right)\mathclose{}}^{2} = 4\] For absolute error loss: \[\mathopen{}\left|3 - 5\right|\mathclose{} = 2\]

  2. For \(c = 1\): The risk under squared error loss is: \[ \begin{aligned} {\mathbb{E}\mathopen{}\left[{\mathopen{}\left(Y - 1\right)\mathclose{}}^{2}\right]\mathclose{}} &= 0.5 \cdot{\mathopen{}\left(0 - 1\right)\mathclose{}}^{2} + 0.5 \cdot{\mathopen{}\left(4 - 1\right)\mathclose{}}^{2} \\ &= 0.5 \cdot 1 + 0.5 \cdot 9 \\ &= 5 \end{aligned} \] The risk under absolute error loss is: \[ \begin{aligned} {\mathbb{E}\mathopen{}\left[\mathopen{}\left|Y - 1\right|\mathclose{}\right]\mathclose{}} &= 0.5 \cdot\mathopen{}\left|0 - 1\right|\mathclose{} + 0.5 \cdot\mathopen{}\left|4 - 1\right|\mathclose{} \\ &= 0.5 \cdot 1 + 0.5 \cdot 3 \\ &= 2 \end{aligned} \]

  3. For \(c = 2\): The risk under squared error loss is: \[ \begin{aligned} {\mathbb{E}\mathopen{}\left[{\mathopen{}\left(Y - 2\right)\mathclose{}}^{2}\right]\mathclose{}} &= 0.5 \cdot{\mathopen{}\left(0 - 2\right)\mathclose{}}^{2} + 0.5 \cdot{\mathopen{}\left(4 - 2\right)\mathclose{}}^{2} \\ &= 0.5 \cdot 4 + 0.5 \cdot 4 \\ &= 4 \end{aligned} \] The risk under absolute error loss is: \[ \begin{aligned} {\mathbb{E}\mathopen{}\left[\mathopen{}\left|Y - 2\right|\mathclose{}\right]\mathclose{}} &= 0.5 \cdot\mathopen{}\left|0 - 2\right|\mathclose{} + 0.5 \cdot\mathopen{}\left|4 - 2\right|\mathclose{} \\ &= 0.5 \cdot 2 + 0.5 \cdot 2 \\ &= 2 \end{aligned} \]

  4. The prediction \(c = 2\) has the smaller risk under squared error loss (\(4\) versus \(5\)). The two predictions have the same risk under absolute error loss (\(2\)), so under absolute error loss this exercise does not choose one of them. The prediction \(c = 2\) equals the expectation: \[ \begin{aligned} {\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} &= 0.5 \cdot 0 + 0.5 \cdot 4 \\ &= 2 \end{aligned} \]

RemarkRemark 5 (The best prediction depends on the loss)

Remark 5 (The best prediction depends on the loss). In Exercise 6 (parts 2 and 3), the risk of the prediction \(c = 1\) is \(5\) for squared error loss and \(2\) for absolute error loss. The risk of the prediction \(c = 2\) is \(4\) for squared error loss and \(2\) for absolute error loss.

The prediction with the smallest risk depends on the loss. In Exercise 6, every constant \(c\) from \(0\) to \(4\) has absolute error risk \(2\), because

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[\mathopen{}\left|Y - c\right|\mathclose{}\right]\mathclose{}} &= 0.5\,c + 0.5\,(4 - c) \\ &= 2. \end{aligned} \]

Only \(c = 2\) has the smallest squared error risk. Under squared error loss, the prediction function that minimizes risk is the conditional mean \({\mathbb{E}\mathopen{}\left[Y \mid X\right]\mathclose{}}\), proved below (Theorem 13). Hastie et al. [13, p. 20] state that, for absolute error loss, the best prediction function is the conditional median instead of the conditional mean. This statement is given here without proof.

ExrExercise 7 (Comparing prediction functions under squared-error loss)

Exercise 7 (Comparing prediction functions under squared-error loss) Let \((X, Y)\) be jointly distributed discrete random variables. \(X\) takes values in \(\{0, 1\}\) with \(\mathbb{P}(X= 0) = 0.5\) and \(\mathbb{P}(X= 1) = 0.5\). Given \(X= 0\), \(Y\) takes values in \(\{0, 2\}\) with conditional probabilities \(\mathbb{P}(Y= 0 \mid X= 0) = 0.5\) and \(\mathbb{P}(Y= 2 \mid X= 0) = 0.5\). Given \(X= 1\), \(Y\) takes values in \(\{4, 6\}\) with conditional probabilities \(\mathbb{P}(Y= 4 \mid X= 1) = 0.5\) and \(\mathbb{P}(Y= 6 \mid X= 1) = 0.5\).

  1. Compute the marginal mean \({\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}}\) and the conditional expectation function \({f^*\mathopen{}\left(X\right)\mathclose{}} \stackrel{\text{def}}{=}{\mathbb{E}\mathopen{}\left[Y\mid X\right]\mathclose{}}\).

  2. Consider the constant prediction \(f_1\mathopen{}\left(X\right)\mathclose{} \stackrel{\text{def}}{=}{\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} = 3\), which ignores \(X\). Compute its squared-error risk \({\mathbb{E}\mathopen{}\left[{\mathopen{}\left(Y- f_1\mathopen{}\left(X\right)\mathclose{}\right)\mathclose{}}^{2}\right]\mathclose{}}\).

  3. Consider the alternate prediction \(f_2\mathopen{}\left(X\right)\mathclose{} \stackrel{\text{def}}{=}4X\). Compute its squared-error risk \({\mathbb{E}\mathopen{}\left[{\mathopen{}\left(Y- f_2\mathopen{}\left(X\right)\mathclose{}\right)\mathclose{}}^{2}\right]\mathclose{}}\).

  4. Compute the squared-error risk \({\mathbb{E}\mathopen{}\left[{\mathopen{}\left(Y- {f^*\mathopen{}\left(X\right)\mathclose{}}\right)\mathclose{}}^{2}\right]\mathclose{}}\) of the conditional mean predictor \({f^*\mathopen{}\left(X\right)\mathclose{}}\). Which of \(f_1\), \(f_2\), and \(f^*\) achieves the lowest risk?

SolutionSolution 3

Solution 3.

  1. For each value of \(X\), compute the conditional expectation: \[ \begin{aligned} {\mathbb{E}\mathopen{}\left[Y\mid X= 0\right]\mathclose{}} &= 0 \cdot 0.5 + 2 \cdot 0.5 \\ &= 1 \end{aligned} \] \[ \begin{aligned} {\mathbb{E}\mathopen{}\left[Y\mid X= 1\right]\mathclose{}} &= 4 \cdot 0.5 + 6 \cdot 0.5 \\ &= 5 \end{aligned} \] By the law of iterated expectations (Theorem 10), the marginal mean is: \[ \begin{aligned} {\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} &= {\mathbb{E}\mathopen{}\left[{\mathbb{E}\mathopen{}\left[Y\mid X\right]\mathclose{}}\right]\mathclose{}} \\ &= 1 \cdot 0.5 + 5 \cdot 0.5 \\ &= 3 \end{aligned} \] The conditional expectation function is \({f^*\mathopen{}\left(0\right)\mathclose{}} = 1\) and \({f^*\mathopen{}\left(1\right)\mathclose{}} = 5\), which can also be written \({f^*\mathopen{}\left(X\right)\mathclose{}} = 1 + 4X\).

  2. For the constant prediction \(f_1\mathopen{}\left(X\right)\mathclose{} = 3\): Given \(X= 0\): \[ \begin{aligned} {\mathbb{E}\mathopen{}\left[{\mathopen{}\left(Y- 3\right)\mathclose{}}^{2} \mid X= 0\right]\mathclose{}} &= {\mathopen{}\left(0 - 3\right)\mathclose{}}^{2} \cdot 0.5 + {\mathopen{}\left(2 - 3\right)\mathclose{}}^{2} \cdot 0.5 \\ &= 9 \cdot 0.5 + 1 \cdot 0.5 \\ &= 5 \end{aligned} \] Given \(X= 1\): \[ \begin{aligned} {\mathbb{E}\mathopen{}\left[{\mathopen{}\left(Y- 3\right)\mathclose{}}^{2} \mid X= 1\right]\mathclose{}} &= {\mathopen{}\left(4 - 3\right)\mathclose{}}^{2} \cdot 0.5 + {\mathopen{}\left(6 - 3\right)\mathclose{}}^{2} \cdot 0.5 \\ &= 1 \cdot 0.5 + 9 \cdot 0.5 \\ &= 5 \end{aligned} \] By the law of iterated expectations (Theorem 10): \[ \begin{aligned} {\mathbb{E}\mathopen{}\left[{\mathopen{}\left(Y- f_1\mathopen{}\left(X\right)\mathclose{}\right)\mathclose{}}^{2}\right]\mathclose{}} &= {\mathbb{E}\mathopen{}\left[{\mathbb{E}\mathopen{}\left[{\mathopen{}\left(Y- 3\right)\mathclose{}}^{2} \mid X\right]\mathclose{}}\right]\mathclose{}} \\ &= 5 \cdot 0.5 + 5 \cdot 0.5 \\ &= 5 \end{aligned} \]

  3. For the prediction \(f_2\mathopen{}\left(X\right)\mathclose{} = 4X\): Here \(f_2\mathopen{}\left(0\right)\mathclose{} = 0\) and \(f_2\mathopen{}\left(1\right)\mathclose{} = 4\).   4. For the conditional mean predictor \({f^*\mathopen{}\left(X\right)\mathclose{}} = {\mathbb{E}\mathopen{}\left[Y\mid X\right]\mathclose{}}\): Given \(X= 0\), \({f^*\mathopen{}\left(0\right)\mathclose{}} = 1\): \[ \begin{aligned} {\mathbb{E}\mathopen{}\left[{\mathopen{}\left(Y- 1\right)\mathclose{}}^{2} \mid X= 0\right]\mathclose{}} &= {\mathopen{}\left(0 - 1\right)\mathclose{}}^{2} \cdot 0.5 + {\mathopen{}\left(2 - 1\right)\mathclose{}}^{2} \cdot 0.5 \\ &= 1 \cdot 0.5 + 1 \cdot 0.5 \\ &= 1 \end{aligned} \] Given \(X= 1\), \({f^*\mathopen{}\left(1\right)\mathclose{}} = 5\): \[ \begin{aligned} {\mathbb{E}\mathopen{}\left[{\mathopen{}\left(Y- 5\right)\mathclose{}}^{2} \mid X= 1\right]\mathclose{}} &= {\mathopen{}\left(4 - 5\right)\mathclose{}}^{2} \cdot 0.5 + {\mathopen{}\left(6 - 5\right)\mathclose{}}^{2} \cdot 0.5 \\ &= 1 \cdot 0.5 + 1 \cdot 0.5 \\ &= 1 \end{aligned} \] By Theorem 10: \[ \begin{aligned} {\mathbb{E}\mathopen{}\left[{\mathopen{}\left(Y- {f^*\mathopen{}\left(X\right)\mathclose{}}\right)\mathclose{}}^{2}\right]\mathclose{}} &= 1 \cdot 0.5 + 1 \cdot 0.5 \\ &= 1 \end{aligned} \] The conditional mean predictor \(f^*\) achieves the lowest risk (\(1\)), strictly outperforming \(f_2\) (\(2\)) and the constant prediction \(f_1\) (\(5\)).

ProofProof

Proof. \[ \begin{aligned} {{\varepsilon_{\text{pred}}}\mathopen{}\left(f\right)\mathclose{}} &= {f\mathopen{}\left(X\right)\mathclose{}} - Y && \text{(definition of } {{\varepsilon_{\text{pred}}}\mathopen{}\left(f\right)\mathclose{}} \text{)} \\ &= \mathopen{}\left({\mu\mathopen{}\left(X\right)\mathclose{}} - Y\right)\mathclose{} + \mathopen{}\left({f\mathopen{}\left(X\right)\mathclose{}} - {\mu\mathopen{}\left(X\right)\mathclose{}}\right)\mathclose{} && \text{(add and subtract } {\mu\mathopen{}\left(X\right)\mathclose{}} \text{)} \\ &= {{\varepsilon_{\text{pred}}}\mathopen{}\left(\mu\right)\mathclose{}} + \mathopen{}\left({f\mathopen{}\left(X\right)\mathclose{}} - {\mu\mathopen{}\left(X\right)\mathclose{}}\right)\mathclose{} && \text{(definition of } {{\varepsilon_{\text{pred}}}\mathopen{}\left(\mu\right)\mathclose{}} \text{)} \end{aligned} \]

LemLemma 3 (The conditional mean’s error is uncorrelated with any function of the input)

Lemma 3 (The conditional mean’s error is uncorrelated with any function of the input) Let \({\mu\mathopen{}\left(X\right)\mathclose{}} \stackrel{\text{def}}{=}{\mathbb{E}\mathopen{}\left[Y\mid X\right]\mathclose{}}\) be the conditional expectation function of \(Y\) given \(X\). For any prediction function \({f\mathopen{}\left(X\right)\mathclose{}}\) with \({\mathbb{E}\mathopen{}\left[{f\mathopen{}\left(X\right)\mathclose{}}^2\right]\mathclose{}} < \infty\):

\[{\mathbb{E}\mathopen{}\left[{{\varepsilon_{\text{pred}}}\mathopen{}\left(\mu\right)\mathclose{}} \cdot\mathopen{}\left({f\mathopen{}\left(X\right)\mathclose{}} - {\mu\mathopen{}\left(X\right)\mathclose{}}\right)\mathclose{}\right]\mathclose{}} = 0\]

ProofProof

Proof. Because \({f\mathopen{}\left(X\right)\mathclose{}} - {\mu\mathopen{}\left(X\right)\mathclose{}}\) is a function of \(X\), by Theorem 8 it factors out of the conditional expectation:

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[{{\varepsilon_{\text{pred}}}\mathopen{}\left(\mu\right)\mathclose{}}\mathopen{}\left({f\mathopen{}\left(X\right)\mathclose{}} - {\mu\mathopen{}\left(X\right)\mathclose{}}\right)\mathclose{} \mid X\right]\mathclose{}} &= \mathopen{}\left({f\mathopen{}\left(X\right)\mathclose{}} - {\mu\mathopen{}\left(X\right)\mathclose{}}\right)\mathclose{} \cdot{\mathbb{E}\mathopen{}\left[{{\varepsilon_{\text{pred}}}\mathopen{}\left(\mu\right)\mathclose{}} \mid X\right]\mathclose{}} && \text{(a function of } X\text{ factors out)} \\ &= \mathopen{}\left({f\mathopen{}\left(X\right)\mathclose{}} - {\mu\mathopen{}\left(X\right)\mathclose{}}\right)\mathclose{} \cdot{\mathbb{E}\mathopen{}\left[{\mu\mathopen{}\left(X\right)\mathclose{}} - Y\mid X\right]\mathclose{}} && \text{(definition of } {{\varepsilon_{\text{pred}}}\mathopen{}\left(\mu\right)\mathclose{}} \text{)} \\ &= \mathopen{}\left({f\mathopen{}\left(X\right)\mathclose{}} - {\mu\mathopen{}\left(X\right)\mathclose{}}\right)\mathclose{} \cdot\mathopen{}\left({\mathbb{E}\mathopen{}\left[{\mu\mathopen{}\left(X\right)\mathclose{}} \mid X\right]\mathclose{}} - {\mathbb{E}\mathopen{}\left[Y\mid X\right]\mathclose{}}\right)\mathclose{} && \text{(linearity of conditional expectation)} \\ &= \mathopen{}\left({f\mathopen{}\left(X\right)\mathclose{}} - {\mu\mathopen{}\left(X\right)\mathclose{}}\right)\mathclose{} \cdot\mathopen{}\left({\mu\mathopen{}\left(X\right)\mathclose{}} - {\mu\mathopen{}\left(X\right)\mathclose{}}\right)\mathclose{} && \text{(a function of } X\text{ is its own conditional mean, and definition of } {\mu\mathopen{}\left(X\right)\mathclose{}} \text{)} \\ &= 0 && \text{(evaluate)} \end{aligned} \]

By the law of iterated expectations (Theorem 10):

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[{{\varepsilon_{\text{pred}}}\mathopen{}\left(\mu\right)\mathclose{}}\mathopen{}\left({f\mathopen{}\left(X\right)\mathclose{}} - {\mu\mathopen{}\left(X\right)\mathclose{}}\right)\mathclose{}\right]\mathclose{}} &= {\mathbb{E}\mathopen{}\left[{\mathbb{E}\mathopen{}\left[{{\varepsilon_{\text{pred}}}\mathopen{}\left(\mu\right)\mathclose{}}\mathopen{}\left({f\mathopen{}\left(X\right)\mathclose{}} - {\mu\mathopen{}\left(X\right)\mathclose{}}\right)\mathclose{} \mid X\right]\mathclose{}}\right]\mathclose{}} && \text{(law of iterated expectations)} \\ &= {\mathbb{E}\mathopen{}\left[0\right]\mathclose{}} && \text{(the conditional expectation is } 0 \text{)} \\ &= 0 && \text{(expectation of a constant)} \end{aligned} \]

For any prediction function \({f\mathopen{}\left(X\right)\mathclose{}}\) with \({\mathbb{E}\mathopen{}\left[{f\mathopen{}\left(X\right)\mathclose{}}^2\right]\mathclose{}} < \infty\):

\[{R\mathopen{}\left(f\right)\mathclose{}} = {R\mathopen{}\left(\mu\right)\mathclose{}} + {\mathbb{E}\mathopen{}\left[{\mathopen{}\left({f\mathopen{}\left(X\right)\mathclose{}} - {\mu\mathopen{}\left(X\right)\mathclose{}}\right)\mathclose{}}^{2}\right]\mathclose{}}\]

ProofProof

Proof. The steps use the squared-error risk definition, Lemma 2, Lemma 3, and Theorem 4:

\[ \begin{aligned} {R\mathopen{}\left(f\right)\mathclose{}} &= {\mathbb{E}\mathopen{}\left[{\mathopen{}\left({{\varepsilon_{\text{pred}}}\mathopen{}\left(f\right)\mathclose{}}\right)\mathclose{}}^{2}\right]\mathclose{}} && \text{(definition of the squared-error risk)} \\ &= {\mathbb{E}\mathopen{}\left[{\mathopen{}\left({{\varepsilon_{\text{pred}}}\mathopen{}\left(\mu\right)\mathclose{}} + {\mathopen{}\left({f\mathopen{}\left(X\right)\mathclose{}} - {\mu\mathopen{}\left(X\right)\mathclose{}}\right)\mathclose{}}\right)\mathclose{}}^{2}\right]\mathclose{}} && \text{(the prediction error splits at } \mu\text{)} \\ &= {\mathbb{E}\mathopen{}\left[{\mathopen{}\left({{\varepsilon_{\text{pred}}}\mathopen{}\left(\mu\right)\mathclose{}}\right)\mathclose{}}^{2}\right]\mathclose{}} + 2 \cdot{\mathbb{E}\mathopen{}\left[{{\varepsilon_{\text{pred}}}\mathopen{}\left(\mu\right)\mathclose{}} \cdot{\mathopen{}\left({f\mathopen{}\left(X\right)\mathclose{}} - {\mu\mathopen{}\left(X\right)\mathclose{}}\right)\mathclose{}}\right]\mathclose{}} + {\mathbb{E}\mathopen{}\left[{\mathopen{}\left({\mathopen{}\left({f\mathopen{}\left(X\right)\mathclose{}} - {\mu\mathopen{}\left(X\right)\mathclose{}}\right)\mathclose{}}\right)\mathclose{}}^{2}\right]\mathclose{}} && \text{(expand the square; LemTheorem 13 (Conditional mean minimizes squared-error risk)

Theorem 13 (Conditional mean minimizes squared-error risk) Let \(X\) and \(Y\) be jointly distributed random variables with \({\mathbb{E}\mathopen{}\left[Y^2\right]\mathclose{}} < \infty\). Let \({\mu\mathopen{}\left(X\right)\mathclose{}} \stackrel{\text{def}}{=}{\mathbb{E}\mathopen{}\left[Y\mid X\right]\mathclose{}}\) be the conditional expectation function of \(Y\) given \(X\). Write \(f^*\stackrel{\text{def}}{=}\mu\) for the prediction function that uses it. Then for any prediction function \({f\mathopen{}\left(X\right)\mathclose{}}\) with \({\mathbb{E}\mathopen{}\left[{f\mathopen{}\left(X\right)\mathclose{}}^2\right]\mathclose{}} < \infty\):

\[{R\mathopen{}\left(f\right)\mathclose{}} \ge {R\mathopen{}\left(f^*\right)\mathclose{}}\]

with equality if and only if \(\mathbb{P}({f\mathopen{}\left(X\right)\mathclose{}} = {f^*\mathopen{}\left(X\right)\mathclose{}}) = 1\). That is, \(f^*\) minimizes the squared-error risk among all prediction functions of \(X\).

ProofProof

Proof. By Theorem 12:

\[ \begin{aligned} {R\mathopen{}\left(f\right)\mathclose{}} - {R\mathopen{}\left(f^*\right)\mathclose{}} &= {\mathbb{E}\mathopen{}\left[{\mathopen{}\left({f\mathopen{}\left(X\right)\mathclose{}} - {f^*\mathopen{}\left(X\right)\mathclose{}}\right)\mathclose{}}^{2}\right]\mathclose{}} && \text{(squared-error risk decomposition)} \\ &\ge 0 && \text{(the expectation of a non-negative variable)} \end{aligned} \]

The expectation of the non-negative variable \({\mathopen{}\left({f\mathopen{}\left(X\right)\mathclose{}} - {f^*\mathopen{}\left(X\right)\mathclose{}}\right)\mathclose{}}^{2}\) is zero if and only if the variable is \(0\) with probability \(1\), meaning \(\mathbb{P}({f\mathopen{}\left(X\right)\mathclose{}} = {f^*\mathopen{}\left(X\right)\mathclose{}}) = 1\).

\[{R\mathopen{}\left(\mu\right)\mathclose{}} = {\mathbb{E}\mathopen{}\left[{\mathopen{}\left({{\varepsilon_{\text{pred}}}\mathopen{}\left(\mu\right)\mathclose{}}\right)\mathclose{}}^{2}\right]\mathclose{}}\]

LemTheorem 14 (The residual risk is the expected conditional variance)

Theorem 14 (The residual risk is the expected conditional variance) Let \(X\) and \(Y\) be as in Theorem 13. Then the residual risk is the expectation of the conditional variance of \(Y\) given \(X\):

\[ {R\mathopen{}\left(\mu\right)\mathclose{}} = {\mathbb{E}\mathopen{}\left[{\operatorname{Var}\mathopen{}\left(Y\mid X\right)\mathclose{}}\right]\mathclose{}}. \tag{1}\]

ProofProof

Proof. \[ \begin{aligned} {R\mathopen{}\left(\mu\right)\mathclose{}} &= {\mathbb{E}\mathopen{}\left[{\mathopen{}\left({{\varepsilon_{\text{pred}}}\mathopen{}\left(\mu\right)\mathclose{}}\right)\mathclose{}}^{2}\right]\mathclose{}} && \text{(definition of the residual risk)} \\ &= {\mathbb{E}\mathopen{}\left[{\mathopen{}\left({\mu\mathopen{}\left(X\right)\mathclose{}} - Y\right)\mathclose{}}^{2}\right]\mathclose{}} && \text{(definition of the prediction error)} \\ &= {\mathbb{E}\mathopen{}\left[{\mathopen{}\left(Y- {\mu\mathopen{}\left(X\right)\mathclose{}}\right)\mathclose{}}^{2}\right]\mathclose{}} && \text{(a square is unchanged by negation)} \\ &= {\mathbb{E}\mathopen{}\left[{\mathopen{}\left(Y- {\mathbb{E}\mathopen{}\left[Y\mid X\right]\mathclose{}}\right)\mathclose{}}^{2}\right]\mathclose{}} && \text{(definition of } \mu\text{)} \\ &= {\mathbb{E}\mathopen{}\left[{{\mathbb{E}\mathopen{}\left[{\mathopen{}\left(Y- {\mathbb{E}\mathopen{}\left[Y\mid X\right]\mathclose{}}\right)\mathclose{}}^{2} \mid X\right]\mathclose{}}}\right]\mathclose{}} && \text{(law of total expectation)} \\ &= {\mathbb{E}\mathopen{}\left[{\operatorname{Var}\mathopen{}\left(Y\mid X\right)\mathclose{}}\right]\mathclose{}} && \text{(definition of conditional variance)} \end{aligned} \]

RemarkRemark 7 (The residual risk does not depend on the prediction function)

Remark 7 (The residual risk does not depend on the prediction function). The residual risk depends only on the joint distribution of \((X, Y)\) and not on the prediction function \(f\), so no choice of \(f\) can achieve a smaller risk. It is the minimum only among prediction functions of the given \(X\): the outcome may also depend on variables that \(X\) leaves out, and those variables are part of the unexplained variation \(Y- {\mathbb{E}\mathopen{}\left[Y\mid X\right]\mathclose{}}\). Measuring one of them and adding it to the variables in \(X\) can lower the residual risk, as in Example 38. [15, Sec. 2.1.1], p. 18 makes the same point: the error term “may contain unmeasured variables that are useful in predicting [\(Y\)]”.

0.4 Entropy and cross-entropy

DefDefinition 21 (Surprisal (self-information, information content))

Definition 21 (Surprisal (self-information, information content)) The surprisal of a possible value \(x\) of a discrete random variable \(X\) with \(\mathbb{P}(X=x) > 0\) is

\[{s\mathopen{}\left(x\right)\mathclose{}} \stackrel{\text{def}}{=}-\log \mathbb{P}(X=x).\]

The surprisal is also called the self-information [16, p. 73] or the information content [17, p. 49] of \(x\). With the natural logarithm, the surprisal is measured in nats, and with base 2 in bits. Evaluating \({s\mathopen{}\left(\cdot\right)\mathclose{}}\) at the random variable \(X\) itself gives the random variable \({s\mathopen{}\left(X\right)\mathclose{}}\), which equals \({s\mathopen{}\left(x\right)\mathclose{}}\) when \(X = x\). The notation leaves the probability mass function of \(X\) implicit.

ExmExample 42 (Surprisal of the values of a biased coin flip)

Example 42 (Surprisal of the values of a biased coin flip) Let \(X\) be \(1\) if one flip of a coin lands heads and \(0\) if it lands tails, with \(\mathbb{P}(X=1) = \tfrac{1}{4}\) and \(\mathbb{P}(X=0) = \tfrac{3}{4}\). Using logarithms to base 2, so that surprisal is measured in bits, the surprisal of the value \(1\) (heads) is \({s\mathopen{}\left(1\right)\mathclose{}} = -\log_2 \tfrac{1}{4} = 2\) bits, and the surprisal of the value \(0\) (tails) is \({s\mathopen{}\left(0\right)\mathclose{}} = -\log_2 \tfrac{3}{4} = \log_2 \tfrac{4}{3} \approx 0.415\) bits. For a fair coin, each value of \(X\) has surprisal \(-\log_2 \tfrac{1}{2} = 1\) bit.

RemarkRemark 9 (Rarer values are more surprising)

Remark 9 (Rarer values are more surprising). A possible value \(x\) with probability \(\mathbb{P}(X=x) = 1\) has surprisal \(0\), and the surprisal grows without bound as \(\mathbb{P}(X=x) \to 0\).

DefDefinition 22 (Entropy)

Definition 22 (Entropy) The entropy of a discrete random variable \(X\) with probability mass function \(\mathbb{P}(X=x)\) is the expectation of its surprisal \({s\mathopen{}\left(X\right)\mathclose{}}\) [18]:

\[{H\mathopen{}\left(X\right)\mathclose{}} \stackrel{\text{def}}{=}{\mathbb{E}\mathopen{}\left[{s\mathopen{}\left(X\right)\mathclose{}}\right]\mathclose{}} = -\sum_{x \in \mathcal{R}(X)} \mathbb{P}(X=x) \log \mathbb{P}(X=x)\]

A term with \(\mathbb{P}(X=x) = 0\) is taken to be \(0\), because \(p \log p \to 0\) as \(p \to 0\).

RemarkRemark 10 (The base of the logarithm is a unit)

Remark 10 (The base of the logarithm is a unit). With the natural logarithm, entropy is measured in nats. With base 2, it is measured in bits. Changing the base multiplies every entropy by the same positive constant. It does not change which distribution has the larger entropy.

ExmExample 43 (Entropy of a coin flip)

Example 43 (Entropy of a coin flip) Let \(X\) be the result of one flip of a coin with \(\mathbb{P}(X=1) = \pi\) and \(\mathbb{P}(X=0) = 1 - \pi\) (Bernoulli distribution). Using logarithms to base 2,

\[H(X) = -\pi\log_2 \pi- (1 - \pi) \log_2 (1 - \pi).\]

For a fair coin, \(\pi= 1/2\), and

\[ \begin{aligned} H(X) &= -\tfrac{1}{2} \log_2 \tfrac{1}{2} - \tfrac{1}{2} \log_2 \tfrac{1}{2} \\ &= \tfrac{1}{2} + \tfrac{1}{2} \\ &= 1 \text{ bit}. \end{aligned} \]

For a coin that always lands heads, \(\pi= 1\), and

\[ \begin{aligned} H(X) &= -1 \cdot \log_2 1 - 0 \\ &= 0. \end{aligned} \]

The outcome is known in advance, so there is no uncertainty to measure. An entropy of \(0\) means that all of the probability is on one outcome.

RemarkRemark 11 (Where the definition comes from)

Remark 11 (Where the definition comes from). Murphy [19, Sec. 2.8.1], p. 56 defines entropy this way, and notes that among distributions on \(K\) outcomes it is largest, \(\log K\), for the uniform distribution.

DefDefinition 23 (Cross-entropy)

Definition 23 (Cross-entropy) Let \(p\) and \(q\) be probability mass functions on the same finite set of outcomes \({\mathopen{}\left\{1, \ldots, K\right\}\mathclose{}}\), with \(p_k\) and \(q_k\) the probabilities of outcome \(k\). The cross-entropy of \(q\) relative to \(p\) [20] is

\[{H\mathopen{}\left(p, q\right)\mathclose{}} \stackrel{\text{def}}{=}-\sum_{k=1}^{K} p_k \log q_k.\]

We take \(-\log 0 = \infty\), so when \(q_k = 0\) for an outcome with \(p_k > 0\), the cross-entropy is infinite. A term with \(p_k = 0\) is taken to be \(0\) whatever \(q_k\) is, as for entropy.

ExrExercise 8 (Mass function of the negative log probability for two mass functions)

Exercise 8 (Mass function of the negative log probability for two mass functions) Let \(X\) have probability mass function \(p = (\tfrac{1}{2}, \tfrac{1}{4}, \tfrac{1}{4})\) on \({\mathopen{}\left\{1, 2, 3\right\}\mathclose{}}\), and let \(q = (\tfrac{1}{4}, \tfrac{1}{2}, \tfrac{1}{4})\) be another probability mass function on \({\mathopen{}\left\{1, 2, 3\right\}\mathclose{}}\). Write \(q_X\) for the random variable that equals \(q_k\) when \(X = k\).

Find the probability mass function of \(Y = -\log_2 q_X\).

SolutionSolution 4

Solution 4. The variable \(Y\) equals \(-\log_2 \tfrac{1}{4} = 2\) when \(X \in {\mathopen{}\left\{1, 3\right\}\mathclose{}}\), and \(-\log_2 \tfrac{1}{2} = 1\) when \(X = 2\). So \(\mathbb{P}(Y = 2) = p_1 + p_3 = \tfrac{3}{4}\) and \(\mathbb{P}(Y = 1) = p_2 = \tfrac{1}{4}\).

ExrExercise 9 (Expected negative log probability for two mass functions)

Exercise 9 (Expected negative log probability for two mass functions) Using the mass function of \(Y = -\log_2 q_X\) from Exercise 8, compute \({\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}}\).

SolutionSolution 5

Solution 5. From the mass function in Solution 4,

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[Y\right]\mathclose{}} &= 2 \cdot\tfrac{3}{4} + 1 \cdot\tfrac{1}{4} \\ &= \tfrac{7}{4}. \end{aligned} \]

ExrExercise 10 (Cross-entropy of two mass functions from the definition)

Exercise 10 (Cross-entropy of two mass functions from the definition) Let \(p = (\tfrac{1}{2}, \tfrac{1}{4}, \tfrac{1}{4})\) and \(q = (\tfrac{1}{4}, \tfrac{1}{2}, \tfrac{1}{4})\) be probability mass functions on \({\mathopen{}\left\{1, 2, 3\right\}\mathclose{}}\).

Compute the cross-entropy \({H\mathopen{}\left(p, q\right)\mathclose{}}\) in bits from its definition.

SolutionSolution 6

Solution 6. From the definition,

\[ \begin{aligned} {H\mathopen{}\left(p, q\right)\mathclose{}} &= -\tfrac{1}{2} \log_2 \tfrac{1}{4} - \tfrac{1}{4} \log_2 \tfrac{1}{2} - \tfrac{1}{4} \log_2 \tfrac{1}{4} \\ &= \tfrac{1}{2} \cdot 2 + \tfrac{1}{4} \cdot 1 + \tfrac{1}{4} \cdot 2 \\ &= \tfrac{7}{4}. \end{aligned} \]

ExrExercise 11 (Cross-entropy and the expected negative log probability)

Exercise 11 (Cross-entropy and the expected negative log probability) Compare your value of \({H\mathopen{}\left(p, q\right)\mathclose{}}\) from Exercise 10 with your value of \({\mathbb{E}\mathopen{}\left[-\log_2 q_X\right]\mathclose{}}\) from Exercise 9, where \(X\) has probability mass function \(p\).

SolutionSolution 7

Solution 7. The cross-entropy equals \({\mathbb{E}\mathopen{}\left[-\log_2 q_X\right]\mathclose{}}\). The two calculations group the same three terms differently: the expectation first combines outcomes 1 and 3, which have the same value of \(-\log_2 q_X\).

ExrExercise 12 (Cross-entropy as an expectation when \(q\) is positive where \(p\) is)

Exercise 12 (Cross-entropy as an expectation when \(q\) is positive where \(p\) is) Let \(p\) and \(q\) be probability mass functions on \({\mathopen{}\left\{1, \ldots, K\right\}\mathclose{}}\) with \(q_k > 0\) whenever \(p_k > 0\). Let \(X\) have mass function \(p\), and write \(q_X\) for the random variable that equals \(q_k\) when \(X = k\). Show that the cross-entropy \({H\mathopen{}\left(p, q\right)\mathclose{}}\) equals the expectation \({\mathbb{E}\mathopen{}\left[-\log q_X\right]\mathclose{}}\).

SolutionSolution 8

Solution 8. Let \(g(k) \stackrel{\text{def}}{=}-\log q_k\), so that \(-\log q_X = g(X)\). Since \(q_k > 0\) whenever \(p_k > 0\), \(g(k)\) is finite for every value \(k\) that \(X\) takes with positive probability. By LOTUS,

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[-\log q_X\right]\mathclose{}} &= {\mathbb{E}\mathopen{}\left[g(X)\right]\mathclose{}} \\ &= \sum_{k : p_k > 0} g(k) \cdot\mathbb{P}(X = k) \\ &= -\sum_{k : p_k > 0} p_k \log q_k \\ &= -\sum_{k=1}^{K} p_k \log q_k \\ &= {H\mathopen{}\left(p, q\right)\mathclose{}}. \end{aligned} \]

The fourth line adds the terms with \(p_k = 0\), which are \(0\) by the convention in the definition.

ExrExercise 13 (Cross-entropy when \(q\) gives zero probability to a possible outcome)

Exercise 13 (Cross-entropy when \(q\) gives zero probability to a possible outcome) Let \(p\) and \(q\) be probability mass functions on \({\mathopen{}\left\{1, \ldots, K\right\}\mathclose{}}\) with \(q_k = 0\) for some \(k\) with \(p_k > 0\). Let \(X\) have mass function \(p\), and write \(q_X\) for the random variable that equals \(q_k\) when \(X = k\).

Find the cross-entropy \({H\mathopen{}\left(p, q\right)\mathclose{}}\).

SolutionSolution 9

Solution 9. By Definition 23, \({H\mathopen{}\left(p, q\right)\mathclose{}} = \infty\).

ExrExercise 14 (Expected negative log probability when \(q\) gives zero probability to a possible outcome)

Exercise 14 (Expected negative log probability when \(q\) gives zero probability to a possible outcome) In the setting of Exercise 13, find the expectation \({\mathbb{E}\mathopen{}\left[-\log q_X\right]\mathclose{}}\).

SolutionSolution 10

Solution 10. Here \(-\log q_X \ge 0\) always, and \(-\log q_X = \infty\) with probability at least \(p_k > 0\), so \({\mathbb{E}\mathopen{}\left[-\log q_X\right]\mathclose{}} = \infty\).

LemTheorem 15 (Cross-entropy as an expected negative log probability)

Theorem 15 (Cross-entropy as an expected negative log probability) Let \(p\) and \(q\) be probability mass functions on \({\mathopen{}\left\{1, \ldots, K\right\}\mathclose{}}\), and let \(X\) have mass function \(p\). Write \(q_X\) for the random variable that equals \(q_k\) when \(X = k\). Then the cross-entropy is the expectation of \(-\log q_X\):

\[{H\mathopen{}\left(p, q\right)\mathclose{}} = {\mathbb{E}\mathopen{}\left[-\log q_X\right]\mathclose{}}.\]

ProofProof

Proof. Let \(g(k) \stackrel{\text{def}}{=}-\log q_k\), so that \(-\log q_X = g(X)\). First suppose \(q_k > 0\) whenever \(p_k > 0\). Then \(g(k)\) is finite for every value \(k\) that \(X\) takes with positive probability, and LOTUS gives

\[ \begin{aligned} {\mathbb{E}\mathopen{}\left[-\log q_X\right]\mathclose{}} &= {\mathbb{E}\mathopen{}\left[g(X)\right]\mathclose{}} && \text{(definition of } g \text{)} \\ &= \sum_{k : p_k > 0} g(k) \cdot\mathbb{P}(X = k) && \text{(LOTUS)} \\ &= -\sum_{k : p_k > 0} p_k \log q_k && \text{(definition of } g \text{ and } \mathbb{P}(X = k) = p_k \text{)} \\ &= -\sum_{k=1}^{K} p_k \log q_k && \text{(terms with } p_k = 0 \text{ are } 0 \text{)} \\ &= {H\mathopen{}\left(p, q\right)\mathclose{}}. && \text{(definition)} \end{aligned} \]

Now suppose \(q_k = 0\) for some \(k\) with \(p_k > 0\). Then \({H\mathopen{}\left(p, q\right)\mathclose{}} = \infty\) by definition. Also \(-\log q_X \ge 0\), and \(-\log q_X = \infty\) with probability at least \(p_k > 0\), so \({\mathbb{E}\mathopen{}\left[-\log q_X\right]\mathclose{}} = \infty\).

ExrExercise 15 (Cross-entropy of a mass function with itself)

Exercise 15 (Cross-entropy of a mass function with itself) Let \(p = (\tfrac{1}{2}, \tfrac{1}{4}, \tfrac{1}{4})\) be a probability mass function on \({\mathopen{}\left\{1, 2, 3\right\}\mathclose{}}\). Compute the cross-entropy \({H\mathopen{}\left(p, p\right)\mathclose{}}\) in bits.

SolutionSolution 11

Solution 11. \[ \begin{aligned} {H\mathopen{}\left(p, p\right)\mathclose{}} &= -\tfrac{1}{2} \log_2 \tfrac{1}{2} - \tfrac{1}{4} \log_2 \tfrac{1}{4} - \tfrac{1}{4} \log_2 \tfrac{1}{4} \\ &= \tfrac{1}{2} \cdot 1 + \tfrac{1}{4} \cdot 2 + \tfrac{1}{4} \cdot 2 \\ &= \tfrac{3}{2} \text{ bits}. \end{aligned} \]

ExrExercise 16 (Entropy of a random variable with a given mass function)

Exercise 16 (Entropy of a random variable with a given mass function) Let \(X\) be a discrete random variable with probability mass function \(p = (\tfrac{1}{2}, \tfrac{1}{4}, \tfrac{1}{4})\) on \({\mathopen{}\left\{1, 2, 3\right\}\mathclose{}}\).

Compute the entropy \({H\mathopen{}\left(X\right)\mathclose{}}\) in bits from its definition.

SolutionSolution 12

Solution 12. The range of \(X\) is \({\mathopen{}\left\{1, 2, 3\right\}\mathclose{}}\), and \(\mathbb{P}(X = k) = p_k\), so

\[ \begin{aligned} {H\mathopen{}\left(X\right)\mathclose{}} &= -\sum_{k \in \mathcal{R}(X)} \mathbb{P}(X = k) \log_2 \mathbb{P}(X = k) \\ &= -\tfrac{1}{2} \log_2 \tfrac{1}{2} - \tfrac{1}{4} \log_2 \tfrac{1}{4} - \tfrac{1}{4} \log_2 \tfrac{1}{4} \\ &= \tfrac{3}{2} \text{ bits}. \end{aligned} \]

ExrExercise 17 (Entropy and the cross-entropy of a mass function with itself)

Exercise 17 (Entropy and the cross-entropy of a mass function with itself) Compare your value of \({H\mathopen{}\left(X\right)\mathclose{}}\) from Exercise 16 with your value of \({H\mathopen{}\left(p, p\right)\mathclose{}}\) from Exercise 15.

SolutionSolution 13

Solution 13. The entropy equals \({H\mathopen{}\left(p, p\right)\mathclose{}}\), because the two sums have the same terms.

ExrExercise 18 (Entropy as a cross-entropy, for any mass function)

Exercise 18 (Entropy as a cross-entropy, for any mass function) Let \(X\) be a discrete random variable with probability mass function \(p\) on \({\mathopen{}\left\{1, \ldots, K\right\}\mathclose{}}\). Show that \({H\mathopen{}\left(p, p\right)\mathclose{}} = {H\mathopen{}\left(X\right)\mathclose{}}\).

SolutionSolution 14

Solution 14. By Theorem 15 with \(q = p\), \({H\mathopen{}\left(p, p\right)\mathclose{}} = {\mathbb{E}\mathopen{}\left[-\log p_X\right]\mathclose{}}\). Since \(\mathbb{P}(X = k) = p_k\), we have \(-\log p_X = {s\mathopen{}\left(X\right)\mathclose{}}\), the surprisal of \(X\). The surprisal \({s\mathopen{}\left(X\right)\mathclose{}}\) is finite with probability 1, because \(X\) takes only values with \(p_k > 0\), and the values with \(p_k = 0\) contribute \(0\) to both \({H\mathopen{}\left(p, p\right)\mathclose{}}\) and \({H\mathopen{}\left(X\right)\mathclose{}}\) by the convention in their definitions. So \({H\mathopen{}\left(p, p\right)\mathclose{}} = {\mathbb{E}\mathopen{}\left[{s\mathopen{}\left(X\right)\mathclose{}}\right]\mathclose{}} = {H\mathopen{}\left(X\right)\mathclose{}}\) by the definition of entropy.

CorCorollary 6 (Entropy is the cross-entropy of a distribution with itself)

Corollary 6 (Entropy is the cross-entropy of a distribution with itself) Let \(X\) be a discrete random variable with probability mass function \(p\) on \({\mathopen{}\left\{1, \ldots, K\right\}\mathclose{}}\). Then

\[{H\mathopen{}\left(p, p\right)\mathclose{}} = {H\mathopen{}\left(X\right)\mathclose{}}.\]

ProofProof

Proof. By Theorem 15 with \(q = p\), \({H\mathopen{}\left(p, p\right)\mathclose{}} = {\mathbb{E}\mathopen{}\left[-\log p_X\right]\mathclose{}}\). Since \(\mathbb{P}(X = k) = p_k\), the random variable \(-\log p_X\) is the surprisal \({s\mathopen{}\left(X\right)\mathclose{}}\). The surprisal \({s\mathopen{}\left(X\right)\mathclose{}}\) is finite with probability 1, because \(X\) takes only values with \(p_k > 0\), and the values with \(p_k = 0\) contribute \(0\) to both \({H\mathopen{}\left(p, p\right)\mathclose{}}\) and \({H\mathopen{}\left(X\right)\mathclose{}}\) by the convention in their definitions. So \({H\mathopen{}\left(p, p\right)\mathclose{}} = {\mathbb{E}\mathopen{}\left[{s\mathopen{}\left(X\right)\mathclose{}}\right]\mathclose{}} = {H\mathopen{}\left(X\right)\mathclose{}}\) by the definition of entropy.

RemarkRemark 12 (Cross-entropy is an expected surprisal)

Remark 12 (Cross-entropy is an expected surprisal). By Theorem 15, the cross-entropy \({H\mathopen{}\left(p, q\right)\mathclose{}}\) is the average surprisal of the values drawn from \(p\), with each surprisal measured by \(q\) as \(-\log q_k\). By Corollary 6, measuring with \(p\) itself gives the entropy.

DefDefinition 24 (Kullback–Leibler divergence (KL divergence, relative entropy))

Definition 24 (Kullback–Leibler divergence (KL divergence, relative entropy)) For \(p\) and \(q\) as in Definition 23, the Kullback–Leibler divergence (KL divergence, or relative entropy) of \(q\) from \(p\) is

\[{{D_{\mathrm{KL}}}\mathopen{}\left(p \,\Vert\, q\right)\mathclose{}} \stackrel{\text{def}}{=}\sum_{k=1}^{K} p_k \log \frac{p_k}{q_k} = {H\mathopen{}\left(p, q\right)\mathclose{}} - {H\mathopen{}\left(p, p\right)\mathclose{}}.\]

RemarkRemark 13 (The divergence is not symmetric)

Remark 13 (The divergence is not symmetric). In general, \({{D_{\mathrm{KL}}}\mathopen{}\left(p \,\Vert\, q\right)\mathclose{}} \ne {{D_{\mathrm{KL}}}\mathopen{}\left(q \,\Vert\, p\right)\mathclose{}}\), so KL divergence is not a distance between \(p\) and \(q\).

ExmExample 44 (Cross-entropy and divergence for two coins)

Example 44 (Cross-entropy and divergence for two coins) Let \(p = (\tfrac{1}{2}, \tfrac{1}{2})\) be a fair coin and \(q = (\tfrac{1}{4}, \tfrac{3}{4})\) a coin biased toward the second outcome. Using logarithms to base 2, \(\log_2 \tfrac{1}{4} = -2\) and \(\log_2 \tfrac{3}{4} = \log_2 3 - 2\), so

\[ \begin{aligned} {H\mathopen{}\left(p, q\right)\mathclose{}} &= -\tfrac{1}{2} \log_2 \tfrac{1}{4} - \tfrac{1}{2} \log_2 \tfrac{3}{4} \\ &= 1 + \tfrac{1}{2} \mathopen{}\left(2 - \log_2 3\right)\mathclose{} \\ &= 2 - \tfrac{1}{2} \log_2 3 \\ &\approx 1.208, \\ {H\mathopen{}\left(p, p\right)\mathclose{}} &= -\tfrac{1}{2} \log_2 \tfrac{1}{2} - \tfrac{1}{2} \log_2 \tfrac{1}{2} \\ &= 1, \\ {{D_{\mathrm{KL}}}\mathopen{}\left(p \,\Vert\, q\right)\mathclose{}} &= {H\mathopen{}\left(p, q\right)\mathclose{}} - {H\mathopen{}\left(p, p\right)\mathclose{}} = 1 - \tfrac{1}{2} \log_2 3 \approx 0.208. \end{aligned} \]

Here the cross-entropy is larger than the entropy of \(p\), and the divergence is the difference.

RemarkRemark 14 (Where the definitions come from)

Remark 14 (Where the definitions come from). Murphy [19, Sec. 2.8.2], pp. 57–58 defines the KL divergence and the cross-entropy as above, and gives the coding interpretation: the cross-entropy is the average number of bits needed to encode data from a source with distribution \(p\) using a code designed for \(q\).
